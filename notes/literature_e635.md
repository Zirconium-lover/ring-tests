| источник | условия | результат |
|---|---|---|
| li2020, рис. 12 | оболочки Zircaloy-4 без H, надрез 0.04–0.08 мм, EDC | J_IC ≈ 7–14 кДж/м² (CW/SR), 10–21 кДж/м² (RX) |
| grigoriev1995, рис. 5 | трубы Zircaloy-2 12.25×0.82, PLT, 20 °C | пласт. раскрытие надреза при F_max: 0.12–0.15 мм (холоднодеформир.), ≈ 0.45–0.5 мм (отожж.); 573 K — больше |
| cockeram2013, с. 9 | прокат Zircaloy-2/4 | K_IC ≈ 33–41 МПа·√м (толстые образцы) |

Оценка u_f ≈ 2·G_c/σ: при G_c ≈ J_IC = 10–20 кДж/м² и σ ≈ 600 МПа получается
**u_f ≈ 0.03–0.07 мм** — в 10–25 раз меньше толщины стенки 0.8 мм.
Раскрытие надреза из grigoriev1995 больше, но это размер притупления
у вершины при максимуме силы, а не перемещение полного разделения.

### 2.5. Испытания раздачей кольца: геометрия, трение, краевые эффекты

- **jiang2018** (конус + 4 клина, Zircaloy-4 Ø 9.5×0.584):
  - высота кольца 4.318 мм (H/t ≈ 7.4) подобрана МКЭ для однородного
    напряжённого состояния; клинья той же высоты;
  - полуугол конуса 13°; зазор клин–кольцо 0.0254 мм по диаметру;
  - трение по МКЭ-подбору: конус–клин μ₁ ≈ 0.07, кольцо–клин μ₂ ≈ 0.1
    (без смазки), клин–опора μ₃ ≈ 0.07;
  - кольцевая деформация = 0.86·Δr/r (поправка на участки над зазорами);
  - разрушение начинается в середине высоты кольца, затем трещина идёт
    срезом; МКЭ без критерия разрушения не воспроизводит шейку.
- **busser2009** (сжатие кольца L = 9.8 мм, t = 0.57): плоская
  деформация с точностью 5 % на 70 % длины; краевая зона ≈ 1.5 мм ≈ 2.5·t
  у каждого торца. Аналогичная зона ожидается у нас там, где кольцо
  изгибается через края сегментов.
- **hellouindemenibus2014**: образцы EDC длиной 30 мм дают две складки
  (локализация у концов вкладыша), которые затем сливаются; короткие образцы
  (20 мм) складок не дают.
- **Kiraly 2018**: кольцевые образцы шириной 2 мм; σ_в окружная на ≈ 6 %
  ниже осевой для Э110.

### 2.6. Скорость деформации

liu2018, табл. 1: σ_т при сжатии растёт на ≈ 25 % при ε̇ от 10⁻³ до 10 с⁻¹.
Квазистатическое испытание (ε̇ ~ 10⁻⁴…10⁻³ с⁻¹) — эффектом можно пренебречь.

Рекристаллизованный образец, три слоя по толщине стенки. Последние три
столбца таблицы — параметры Кернса f (доли базисных полюсов) по
направлениям R (радиальное), T (окружное), L (осевое). Сумма в каждой
строке = 1.000, что подтверждает прочтение фото.

|---|---|---|---|---|
| наружный | 2.3.1 | 0.520 | 0.382 | 0.098 |
| **средний** | **2.3.2** | **0.504** | **0.377** | **0.119** |
| внутренний | 2.3.3 | 0.557 | 0.317 | 0.126 |
| (для сравнения, другой образец) | 2.4.1 | 0.495 | 0.422 | 0.083 |

Для модели (если вводить анизотропию) — средний слой.
Остальные столбцы таблицы (доли фаз ≈ 97.5/2.5 %, параметры решёток
α-Zr a ≈ 3.229, c ≈ 5.153 Å и второй фазы a ≈ 5.371, c ≈ 8.656 Å — по
значениям похоже на фазу Лавеса Zr(Nb,Fe)₂, и др.) для модели не нужны;
их смысл со слов пользователя не уточнялся.

Качественно: базисных полюсов вдоль оси мало (f_L ≈ 0.12), поэтому
осевое растяжение идёт легко (призматическое скольжение), а окружное —
труднее (f_T ≈ 0.38); утонение стенки затруднено (f_R ≈ 0.5) — ожидаются
большие R и окружная текучесть выше осевой, как в литературе (2.2).
Для сравнения: у рекристаллизованной трубы Zircaloy-4 из liu2018
f_T = 0.65 и отношение σ_т окружн./осев. = 1.34 (сжатие); у канала
Э635 f_T заметно меньше, значит и анизотропия текучести, вероятно, слабее.

**Параметры Кернса не дают коэффициенты Хилла напрямую.** Нужен либо
поликристаллический расчёт (Тейлор/VPSC с CRSS систем скольжения —
например, из Marashi 2024, табл. 2, но это чистый Zr), либо измеренные
R и отношение пределов текучести по оси и по окружности.

## 3. Выводы для модели

1. **Данных по трубе из Э635 в пакете нет.** Ближайшие по составу:
   оболочка Zr–1Sn–1Nb–0.1Fe (Li 2022: окружные σ_0.2 = 725, σ_в = 855 МПа,
   δ = 20 % — но с 260 ppm H и, судя по прочности, не в рекристаллизованном
   состоянии) и лист Mat B из Zhang 2023 (K, n, R по трём направлениям).
   Для первой версии кривой упрочнения можно взять направление TD листа
   Mat B (σ_т ≈ 459 МПа, K ≈ 653 МПа, n ≈ 0.082) — с оговоркой, что это
   лист, а не канал. Нужны собственные данные пользователя (паспорт: σ_0.2,
   σ_в, δ по оси и по окружности при 20 °C).
2. **Анизотропия сильная**: R = 3–7, окружная текучесть выше осевой
   на 10–35 %. Изотропная модель Мизеса завысит утонение стенки
   и занизит деформацию начала шейки. Для первой версии допустимо
   (решатель проверен только с изотропной пластичностью), но это
   систематическая ошибка, которую надо оценить отдельно.
3. **ε_f сильно зависит от стеснения**: одноосное окружное растяжение
   0.64 против 0.21 при плоской деформации (Zircaloy-4 CWSR). Трение
   сегмент–кольцо, создающее осевое напряжение, прямо снижает
   пластичность → довод за смазку и низкое кольцо (task.md, п. 2).
4. **Форма ε_f(η)** для вязкого закона: по Cockeram — монотонный спад
   примерно вдвое от η = 0.33 до η ≈ 1 (≈ 0.9 → ≈ 0.5 для отожжённого
   металла), минимум ≈ 0.15–0.2 при высоких η. Абсолютный уровень для
   канала калибровать по опыту (одноосная ε_f или ψ).
5. **Масштаб u_f**: 0.03–0.07 мм по J_IC тонкостенных оболочек. Совпадает
   с прежней оценкой (0.01–0.05 мм); при размере элемента 0.08–0.1 мм
   проверка L·σ_y/(u_f·E) ≈ 0.1·460/(0.05·95 000) ≈ 0.01 ≪ 1 выполняется.
6. **Высота кольца**: аналог Jiang 2018 выбрал H/t ≈ 7.4 расчётом;
   для t = 0.8 это H ≈ 6 мм. Это ориентир для серии H = 3, 5, 8, 12 мм.
7. **Трение**: μ ≈ 0.07 (смазанные стальные пары) и ≈ 0.1 (кольцо–клин
   без смазки) — разумные значения для серии вместе с μ = 0 и 0.2.

## 4. Чего не хватает

- Кривые σ–ε трубы Э635 по оси и по окружности (паспорт или испытания) —
  пользователь ищет.
- Одноосная ε_f или ψ для канала Э635 — для калибровки уровня ε_f(η).
- Для анизотропии: R-коэффициенты или отношение σ_т окружн./осев.
  канала Э635 (текстура есть, см. 2.7), и пластичность по Хиллу
  в решателе (см. task.md).
