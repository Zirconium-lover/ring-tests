Постановка — `stage1_setup.md`. Таблица — `../runs/stage1/summary.md`.
Графики — `figs/stage1_force.png`, `figs/stage1_profiles.png`,

## 1. Высота кольца

Критерий (заданный до расчёта): величины в середине высоты при H и при
следующей по величине высоте различаются меньше чем на 3 %.

Отличие максимальной окружной деформации на внутренней поверхности в середине
высоты (ε_θ,max) от следующей высоты, C3D4:

| μ | 3 → 5 мм, ε_ном 0.10 / 0.20 | 5 → 8 мм | 8 → 12 мм |
|---|---|---|---|
| 0 | 2.5 / 4.5 % | 1.0 / 3.3 % | −0.7 / 1.4 % |
| 0.05 | 4.6 / 7.7 % | 3.1 / 5.2 % | 0.0 / 1.9 % |
| 0.2 | 7.8 / 10.2 % | 6.5 / 8.3 % | 0.6 / 2.0 % |

То же для трёхосности в опасной точке: 8 → 12 мм — не более 0.6 % при μ ≤ 0.05
и 2.1–2.8 % при μ = 0.2.

**Вывод: H = 8 мм удовлетворяет критерию при всех трёх μ; H = 5 мм — нет
(при ε_ном = 0.20 отличие 3.3–8.3 %).** Сила на конусе на единицу высоты от H
практически не зависит (мембранная работа кольца), отличие — только при μ = 0.2
(до 1.3 %).

Оговорки:
- при μ = 0.2 σ_zz/σ_θθ в середине высоты продолжает расти с H (0.31 → 0.33
  при ε_ном = 0.10, 8 → 12 мм) — это осевое стеснение от трения, которое
  накапливается по высоте (оценка task.md, п. 2), критерий по ε и η оно
  пока не нарушает;
- концентрация ε_max/ε_ср на внутренней поверхности для 8 и 12 мм выходит
  на плато 1.27–1.33, у 3 и 5 мм продолжает расти с нагрузкой (короткое
  кольцо локализуется сильнее).

## 2. Где максимум и где, вероятно, начнётся разрушение

- Максимум деформации — на внутренней поверхности **над зазором между
  сегментами** (φ ≈ 22°; край сегмента — 21.46°), где кольцо изгибается
  через кромку сегмента. Это совпадает с [P2015] (пик у края сегмента при
  трении).
- **У торца над зазором деформация выше, чем в середине высоты**: при
  H = 12, μ = 0.05, ε_ном = 0.20 — 0.248 против 0.228 (+9 %). Значит,
  разрушение, вероятно, начнётся у свободного торца — как в опытах [R2008]
  (очаг на кромке образца).
- Максимум силы при ε_ном ≈ 0.10 (0.086–0.091 при μ = 0.2) — до него
  деформация распределена, после — локализуется над зазором.

## 3. Трение сегмент–кольцо

При H = 3 мм и ε_ном = 0.20: ε_max над зазором 0.238 (μ = 0) → 0.263 (0.05) →
0.323 (0.2), η в опасной точке 0.48 → 0.51 → 0.60. Сила на конусе при этом
почти не меняется (1.21 → 1.23 кН): трение не видно по силе, но оно
перераспределяет деформацию в зазор и повышает трёхосность, то есть снижает
пластичность. **Смазка сегмент–кольцо критична; целевой уровень μ ≤ 0.05.**

## 4. Тип элемента (контроль запирания)

H = 5 мм, μ = 0.05:

| величина | C3D4 | C3D8I | C3D20R (эталон) |
|---|---|---|---|
| ε_θ,max сер., ε_ном 0.10 / 0.20 | 0.1218 / 0.2439 | 0.1160 / 0.2155 | считается |
| η в опасной точке, 0.10 / 0.20 | 0.498 / 0.491 | 0.376 / 0.387 | считается |
| σ_zz/σ_θθ, 0.10 / 0.20 | 0.254 / 0.238 | 0.137 / 0.085 | считается |
| F_z,max, Н | 2091 | 2085 | считается |

Сила и средние деформации совпадают, но в опасной точке C3D4 даёт заметно
бо́льшую трёхосность и σ_zz, чем C3D8I. Если эталон C3D20R подтвердит C3D8I,
это объёмное запирание линейных тетраэдров, и для этапа 2 (где удаление
работает только с C3D4) это надо учитывать при калибровке ε_f(η).
