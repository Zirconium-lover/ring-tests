# Этап 1: итоги — тип элемента, высота кольца, трение, сетка для этапа 2

Постановка — `stage1_setup.md`. Таблица всех расчётов — `../runs/stage1/summary.md`.
Расчёт — сектор 22.5° × H/2 (середина сегмента — середина зазора, середина
высоты — торец), u_r сегмента 0 → 2 мм (ε_ном = u_r/R_i = 0 → 0.364), без
разрушения. Все расчёты ниже дошли до u_r = 2 мм с rc = 0.

Серии:
- C3D4, 6 тетраэдров на шестигранник (Kuhn), шаг 0.1 мм — H = 3, 5, 8, 12 × μ = 0, 0.05, 0.2;
- C3D8I, та же сетка без разрезания — те же 12 случаев;
- эталон C3D20R (квадратичные, 8 × 22 × 25 элементов), H = 5, μ = 0.05;
- C3D4 x24 (24 тетраэдра на шестигранник, через центры граней и объёма), H = 5, μ = 0.05.

Опасная точка — точка интегрирования с наибольшей PEEQ в слое z = 0;
η и σ_zz/σ_θθ в ней даны средними по элементам в радиусе 0.15 мм
(одна точка тетраэдра шумит на ±0.1 по η). Карта ε_θ(φ, z) по всей
внутренней поверхности — `tools/surfmap_stage1.py` (из поля U в .frd).
Начало локализации — ε_ном, при котором ε_θ,max в середине высоты растёт
вдвое быстрее номинальной (dε_max/dε_ном ≥ 2).

- **C3D4 с 6 тетраэдрами** при пластике запирается (объёмное запирание
  линейных тетраэдров при несжимаемом течении): завышает трёхосность
  на 30–35 % и σ_zz вчетверо, ставит максимум деформации и утонения
  не туда (над серединой зазора вместо зоны под сегментом у кромки)
  и **не локализуется вовсе** — ни в одном из 12 расчётов. Сила при этом
  совпадает с эталоном (0.3 %), поэтому по F(u) ошибку не видно.
  Выводы о высоте первой редакции этой записки (по C3D4) отменяются.
- **C3D8I** совпадает с эталоном по месту максимума, утонению и η,
  деформацию завышает на 1–3 % (у торца до 4 %). Серия по высоте
  и трению пересчитана на C3D8I.
- **C3D4 x24** (тот же шаг 0.1 мм) совпадает с эталоном в пределах 1–2 %
  по всем величинам, включая начало локализации. Это сетка для этапа 2
  (удаление элементов в решателе работает только с C3D4).
- Место максимума у C3D8I, x24 и C3D20R совпадает с расчётом [R2008]
  (2D, μ = 0): максимум деформации и минимум толщины при φ ≈ 15–16°
  от середины сегмента.
