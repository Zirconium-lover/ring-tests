# Этап 1: постановка — выбор высоты кольца (без разрушения)

> Итоги — `stage1_results.md`. По ходу этапа постановка расширена:
> C3D4 с 6 тетраэдрами оказался запирающимся, поэтому вся серия
> пересчитана на C3D8I (плюс H = 16 и 20 мм), добавлены эталон C3D20R
> и сетка C3D4 x24 (24 тетраэдра на шестигранник) для этапа 2.

Картинки: `figs/stage1_mesh_H5.png` (геометрия и сетка), `figs/hardening_AB.png`
(кривые упрочнения). Колоды: `tools/mkstage1.sh` → `runs/stage1/decks/`
(генератор `tools/mksector.py`; в git колоды не хранятся).

## Цель

1. Найти минимальную высоту кольца H, при которой в середине высоты нет
   краевых эффектов (task.md, «Краевые эффекты»).
2. Оценить влияние трения сегмент–кольцо.
3. Получить путь нагружения (η, ε_p) в опасной точке — для калибровки
   ε_f(η) перед этапом 2 (разрушение).

Повреждения на этом этапе нет: до начала локализации сектор с симметрией
корректен, а удаление элементов здесь не нужно.

## Геометрия

| | значение |
|---|---|
| кольцо | Ø_вн 11.0, Ø_нар 12.6 мм, t = 0.8 мм |
| оправка | 8 сегментов, конус 20° при вершине (u_r = u_z·tan 10°) |
| пропил между сегментами | 0.2 мм по R_i → край сегмента φ_e = 21.46° |
| сегмент | жёсткий, наружный радиус = R_i (без зазора), выступает за торец кольца на 1 мм |
| конус | не моделируется: сегмент получает радиальное перемещение u_r |

## Расчётная область и граничные условия

Сектор 1/16 кольца: φ ∈ [0, 22.5°] (от середины сегмента до середины зазора),
z ∈ [0, H/2].

| поверхность | условие |
|---|---|
| φ = 0 (середина сегмента) | u_y = 0 |
| φ = 22.5° (середина зазора) | нормальное перемещение 0 (уравнение) |
| z = 0 (середина высоты) | u_z = 0 |
| z = H/2 (торец) | свободен |
| все узлы сегмента | u_x = u_r(t), u_y = u_z = 0 |

## Сетка

Структурная по (r, φ, z) с шагом ≈ 0.1 мм: 8 элементов по толщине, 22 по дуге,
H/(2·0.1) по высоте. Каждый шестигранник режется на 6 тетраэдров C3D4 —
тот же тип, что нужен для удаления на этапе 2.

| H, мм | H/t | C3D4 | узлов |
|---|---|---|---|
| 3 | 3.75 | 15 840 | 4 236 |
| 5 | 6.25 | 26 400 | 6 642 |
| 8 | 10.0 | 42 240 | 10 251 |
| 12 | 15.0 | 63 360 | 15 063 |

Сегмент: 1 слой C3D8, фасетки 0.05 мм по дуге (погрешность цилиндра ~10⁻⁴ мм).

**Контроль запирания.** Линейные тетраэдры при пластическом (несжимаемом)
течении склонны к объёмному запиранию: завышают жёсткость и откладывают
шейку. Контрольный расчёт H = 5 мм, μ = 0.05 на C3D8I (та же сетка без
разрезания, 4 400 шестигранников) покажет величину этой ошибки.

## Материал

Э635, изотропная пластичность (Мизес), кривая **B**:
σ = 653·(0.0116 + ε_p)^0.082 МПа (σ_0.2 = 459, σ_в,инж ≈ 496 МПа при
ε_p ≈ 0.07); таблица `*Plastic` до ε_p = 2. E = 90.5 ГПа, ν = 0.35.
Источники — `literature_e635.md`.

## Контакт

Node-to-surface: ведомые — узлы внутренней поверхности кольца, ведущая —
наружная грань сегмента. Штраф 10⁶ МПа/мм (проникание ~10⁻⁴ мм при
100 МПа), трение Кулона μ, жёсткость прилипания 10⁵ МПа/мм.
Surface-to-surface не используется (падает при удалении, этап 0).

## Нагружение и решатель

u_r сегмента 0 → 2.0 мм (≈ 36 % по R_i) монотонно, Nlgeom, шаг
Δt ≤ 0.005 (Δu_r ≤ 0.01 мм), минимальный 10⁻⁶. Окружение — `tools/run_case.sh`
(умолчания run_s3rad.sh + проверенный набор; переключатели повреждения
здесь не действуют). Запуск — `BG=1` (setsid nohup).

## Выход

| что | частота |
|---|---|
| сила на полусегмент F_x(u_r) (сумма RF по узлам сегмента) | каждые 5 инкрементов |
| перемещения узлов на внутр./наруж. поверхности в z = 0 и z = H/2 по всей дуге | каждые 5 инкрементов |
| S и PEEQ всех элементов слоёв z = 0 и z = H/2 (вся толщина и дуга) | каждые 5 инкрементов |
| поля U и PEEQ (.frd) | каждые 5 инкрементов |

Частота одна на всё: в CalculiX `FREQUENCY=` у `*NODE PRINT` и `*NODE FILE`
пишется в одну переменную (`jout(1)`), последняя побеждает.

Постобработка: ε_θ(φ) на внутренней и наружной поверхностях в середине высоты
и на торце; утонение t(φ); σ_zz и трёхосность η в опасной точке; начало
шейки (рост ε_max/ε_min и ускорение локальной деформации по u_r); F(u_r)
и сила на конусе F_z = 32·F_x·tan(θ/2) (модель — 1/16 по дуге и 1/2 по высоте;
без трения конус–сегмент).

## Серия и критерий

H = 3, 5, 8, 12 мм × μ = 0, 0.05, 0.2 → 12 расчётов + контроль C3D8I.
Первым идёт H = 5, μ = 0.05 (замер времени), затем остальные.

Критерий выбора H: величины в середине высоты (ε_θ(φ), η, σ_zz/σ_θ, u_r начала
шейки) при H и при следующей по величине высоте различаются меньше чем на 3 %.
Дополнительно сравнивается торец с серединой: ширина зоны, где они различаются.

## Допущения и что они могут исказить

- Изотропия: у реальных труб R = 3–7, утонение завышено, шейка раньше.
- Жёсткий сегмент без зазора, острая кромка: у Нилссона сегменты
  пластически деформировались в углу; кромка — место концентрации.
- Одно μ на всей поверхности контакта; трение конус–сегмент не моделируется
  (влияет только на силу F_z, не на деформации кольца).
- Тетраэдры C3D4 — запирание; оценивается контрольным C3D8I.
- После начала локализации симметрия сектора навязывает зеркальную картину;
  результаты дальше начала шейки — только качественные.

## Оценка времени

Проверочная колода (H = 3, упругость, 4 инкремента) — 4 с. С пластикой
ожидается ≥ 200 инкрементов по 4–6 итераций: H = 3 — порядка 10 мин,
H = 12 — 30–60 мин; вся серия — 4–8 ч при одном-двух расчётах одновременно.
Механизмы спасения сходимости решателя с контактом отключены (этап 0),
поэтому после начала шейки возможны остановки по минимальному шагу.
