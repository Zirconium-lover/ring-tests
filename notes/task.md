# Постановка: испытание направляющего канала на сегментной оправке

Состояние на 2026-10-03. Пометка «?» — вопрос открыт.

## Объект

- Кольцо из направляющего канала: Ø_вн = 11.0 мм, Ø_нар = 12.6 мм, t = 0.8 мм.
  R_i = 5.5, R_mid = 5.9, R_o = 6.3 мм; √(R·t) = 2.17 мм.
- Высота образца: доступно до 25–30 мм по оси. Цель — минимальная высота,
  при которой нет краевых эффектов.
- Не гидриды: нужна модель вязкого разрушения.
- Сплав Э635, рекристаллизованный, необлучённый; испытание при комнатной
  температуре. Текстура (параметры Кернса по слоям) — в
  `literature_e635.md`, п. 2.7. ? Кривые σ–ε канала — пользователь ищет.
- ? Оправка: существующая или проектируется; число сегментов, угол конуса,
  материал сегментов, высота сегментов относительно кольца, смазка.

## Принятые решения

- Сегменты моделируются как контактные тела с трением μ (вариант А).
  Нужна предварительная проверка совместимости контакта с удалением
  элементов в ccx-arch2 c75ad9b (не проверялось в регрессионном наборе).
- Расчётная область — сектор полсегмента (22.5° при 8 сегментах)
  с условиями симметрии, но с контролем того, что плоскости симметрии
  не вносят краевых эффектов (см. ниже).
- Сетка трубки только C3D4: удаление элементов, HINGE, DEADSOLE,
  BARE_MASK и FRACTURE_CUT в решателе работают только с C3D4.
- Пластичность: изотропная по Мизесу (`*Plastic`), закон повреждения
  читает эквивалентную пластическую деформацию из xstate(1).
- Анизотропия пластичности (Хилл) в ccx-arch2 c75ad9b **недоступна**:
  `ANISO_PLAS` в `src/umat_main.f` закомментирован, `ortho_plas.f` — это
  ортотропная упругость с изотропной пластичностью, а закон повреждения
  работает только со встроенной `*Plastic`. Ввод анизотропии = доработка
  решателя (не наша зона, ccx-arch2 только как решатель). Первая версия —
  изотропная, с окружной кривой упрочнения; систематическая ошибка
  (утонение, начало шейки) оценивается отдельно.

## Краевые эффекты: оценки до расчёта

1. **Без трения** и при сегментах выше кольца задача однородна по высоте:
   обобщённое плоское напряжение, σ_zz = 0 во всём объёме. Высота на
   решение до локализации не влияет, торцевого эффекта нет.
2. **Трение** мешает осевому укорочению кольца. При пластике
   ε_zz ≈ −ε_θ/2, при ε_θ = 0.3 и H = 5 мм концы смещаются на ≈ 0.35 мм
   относительно середины. Сдвиговое напряжение μ·p, p ≈ σ_θ·t/R_i,
   накапливает в середине высоты σ_zz/σ_θ ≈ μ·H/(2·R_i):
   - H = 5 мм: 2 % при μ = 0.05, 14 % при μ = 0.3;
   - H = 25 мм: 11 % при μ = 0.05, 68 % при μ = 0.3.

   Трение сдвигает середину высокого кольца к плоской деформации и меняет
   трёхосность. Это довод за **низкое** кольцо.
3. **Изгибный пограничный слой** оболочки, если нагрузка неоднородна
   по высоте (сегмент ниже кольца, фаски, перекос):
   ℓ = √(R·t)/[3(1−ν²)]^{1/4} ≈ 1.7 мм; затухание до ≈ 5 % на 3ℓ ≈ 5 мм.
4. **Ширина полосы и локализация.** Кольцо при раздаче работает как полоса
   шириной H и толщиной t = 0.8 мм, растягиваемая по окружности; торцы —
   её боковые кромки. В узкой полосе (H всего в несколько t) шейка
   охватывает сразу всю высоту, и торцы участвуют в разрушении по всей длине
   трещины. В широкой середина высоты работает как длинная труба (утонение
   только по толщине), а разрушение идёт наклонной полосой среза через всю
   высоту, как в опытах [R2008] (≈ 45°, по окружности ≈ H). Если H меньше
   какого-то порога, деформация разрушения будет другой, чем у материала
   трубы. Порог порядка нескольких t, точнее даст расчётная серия.
   Это довод за **не слишком низкое** кольцо. См. `figs/setup_scheme.png`.
5. **Плоскости симметрии.** Зеркальная симметрия по φ = 0, φ = 22.5°
   и по середине высоты точна до локализации. После неё она навязывает
   зеркальные (V/X) полосы и по трещине в каждом секторе (16 при восьми
   сегментах), хотя реальное кольцо рвётся в одном месте и разгружается
   целиком. Значит, сектор пригоден для изучения высоты, трения и сетки
   до начала локализации, а для стадии разрушения нужна модель без
   плоскостей симметрии через ожидаемую трещину.

## Расчётная постановка (предложение)

Схема: `figs/setup_scheme.png` (`tools/plot_setup_scheme.py`).

**Этап 0. Проверка решателя.** Маленькая колода: жёсткий сегмент,
контакт с трением, C3D4 с вязким повреждением и удалением. Вопрос один:
работают ли контакт и удаление вместе в ccx-arch2 c75ad9b.

**Этап 1. Выбор высоты (без разрушения).**
- Область: 1/16 кольца — сектор 22.5° (от середины сегмента до середины
  зазора) × половина высоты; симметрия на трёх гранях, верхний торец свободен.
- Сегмент жёсткий, выше кольца, смещается радиально на u_r
  (эквивалент хода конуса u_z = u_r/tan(θ/2)). Конус не моделируется.
- Контакт сегмент–кольцо, трение μ = 0, 0.05, 0.2.
- Материал: упругопластичность (Мизес) по временной кривой, повреждения нет.
- Серия: H = 3, 5, 8, 12 мм × три μ.
- Результаты: распределения ε_θ, утонения, σ_zz и трёхосности по φ и z;
  u_r начала локализации; сила на сегменте.
- Критерий: минимальная H, для которой эти величины в середине высоты
  отличаются от следующей по величине H меньше заданного допуска.
  Попутно — путь нагружения η(ε_p) в опасной точке для калибровки ε_f(η).

**Этап 2. Разрушение при выбранной H.**
- Область без плоскостей симметрии через трещину: полное кольцо (или
  половина) с мелкой сеткой там, где этап 1 покажет максимум деформации.
- Вязкое повреждение (ε_f(η), u_f) и удаление C3D4.
- Результаты: деформация разрушения, путь и ориентация трещины, F(u_z).

## Данные, которых нет

- Кривая упрочнения сплава до больших деформаций (по окружности).
- ε_f(η) для вязкого закона (Npoints ≥ 2) и масштаб u_f.
- Коэффициенты трения пары сплав — материал сегмента.
