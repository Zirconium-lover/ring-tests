# Фундамент для модели гидридов

`fund.pdf` — собственное изложение основ, без которых трудно понять модель гидридов (`../automaton`) и
учебник по ней (`../textbook`):
- термодинамика и растворы (энергия Гиббса, химический потенциал, общая касательная, растворимость,
  гистерезис TSSD–TSSP, угол диаграммы Zr–H);
- диффузия (случайное блуждание, законы Фика, водород в цирконии, эффект Горского, численные схемы);
- кристаллы и дефекты (ГПУ решётка, гидриды, дислокации, межфазные границы и границы зёрен);
- упругость включений (собственная деформация, задача Эшелби, тонкая пластинка, поле вокруг неё, работа
  нагрузки, метод Фурье);
- зарождение и рост (классическая теория, С-кривые, неоднородное зарождение, сдвиг под нагрузкой,
  кинетика Аврами, Гиббс–Томсон);
- пластичность и текстура (текучесть, пластическая зона и память, межзёренные напряжения, факторы Кернса);
- приложения: справочные величины для Zr–H, ответы к упражнениям, что читать дальше.

Все рисунки посчитаны по формулам текста. Энергия включений (рис. 5.3, 5.4) — тем же методом Фурье, что в
модели; для чистого расширения расчёт сходится с точной теорией Эшелби в пределах 1 %.

Сборка:

```bash
cd figs_src && for f in figs_*.py; do python $f; done   # рисунки → ../figs (matplotlib + LaTeX, T2A)
cd .. && pdflatex fund.tex && pdflatex fund.tex
```
