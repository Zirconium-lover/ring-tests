# hydrides/ — гидриды на снимках сечения стенки

`hydride_spec.py` — анализ снимка поперечного сечения стенки (оптика или СЭМ):
ориентация гидридов **по масштабам**, профили по толщине, связность через стенку.
Снимки шлифов и статьи в git не кладём (репозиторий публичный) — здесь только код.

## Запуск

```bash
# оптика, масштаб известен
python hydride_spec.py снимок.jpg --um-per-px 0.862 --crop 0,1616,0,1130 --out out
# масштаб по линейке (длина линейки в пикселях ищется сама)
python hydride_spec.py снимок.jpg --bar-um 200 --out out
# СЭМ после полосового фильтра: заливка не отличается от металла —
# дать примерные строки поверхностей (наружная, внутренняя), они уточнятся сами
python hydride_spec.py снимок.png --um-per-px 0.847 --surface-guess 8,298 --scales 1.5,3,6,12 --layers 6
```

Наружная поверхность должна быть сверху (иначе `--outer bottom`). `--crop` убирает
подписи и линейку. `--ro-mm` фиксирует известный наружный радиус трубы.

Выход: `*_report.png` (9 панелей) и `*_metrics.json`.

## Что считается и как читать

1. **Развёртка.** К поверхностям подгоняются концентрические окружности, дуга
   разворачивается в полосу «дуга × глубина» (строка 0 — наружная поверхность).
2. **Сигнал гидридов** — «чёрный цилиндр»: насколько точка темнее светлого
   окружения. Не зависит от неравномерной подсветки.
3. **Доля радиальных по масштабу Fn(σ).** Сглаживание гауссом σ и вторые
   производные считаются одним умножением в пространстве Фурье. Направление
   линии берётся из собственных векторов матрицы вторых производных, длина —
   по скелету линий. Fn — доля длины, отклонённой от окружного направления
   больше чем на 45° (в json есть и RHF с весами Simon et al.).
   - Малое σ (1–3 мкм) — отдельные гидриды. Большое σ (12–24 мкм) — то, как
     они выстроены (цепочки, сетка).
   - На крупном масштабе 50 % значит «расположение без предпочтения». Меньше —
     цепочки вдоль дуги, больше — цепочки через стенку.
   - Fn падает с ростом σ — радиальные элементы короткие (перемычки между
     окружными цепочками). Fn растёт — радиальные элементы длинные.
4. **Профили по толщине:** доля площади и Fn(σ) по слоям (`--layers`).
5. **Связность.** Наименьший зазор матрицы, при котором гидриды связывают две
   стороны окна (через стенку и вдоль дуги). Доля матрицы на лучшем пути
   трещины через стенку — двумя способами: по любым гидридам и **только по
   радиальным**. Второй ближе к механике: окружный гидрид окружным напряжением
   не раскрывается.
6. **Проверка спектром:** доля радиальных по углу энергии двумерного спектра
   (`spectral_Fn_thirds`). Это другой вес: длинные контрастные линии весят
   больше. Совпадает с Fn, когда длины радиальных и окружных элементов похожи.

## Проверено

- Синтетика (известная ориентация): все окружные — Fn ≈ 0.01–0.06 на мелком
  масштабе; все радиальные — 0.95–1.0; смесь 30 % — 0.31–0.34; «цепочки через
  стенку из окружных игл» — 0.10 на 1 мкм и 0.99 на 8 мкм.
- 8 СЭМ-снимков ячеек дистанционирующей решётки (рукопись МИФИ): 3 из 4
  трендов Fn по толщине совпадают с текстом рукописи (участки 1, 3 — растёт к
  внутренней поверхности, 4 — к наружной); абсолютные значения выше рис. 5d.
- Порог выделения линий 0.15–0.40: Fn меняется на ±0.05–0.07, тренды и
  порядок снимков — нет.

## Ограничения

- Травление утолщает гидриды: доля площади и связность на оптике завышены.
- Один снимок — это одно поле. Устойчивая доля радиальных требует окна
  ≥ 200–300 мкм (3–4 расстояния между радиальными гидридами); для сравнения
  состояний нужны несколько полей или панорама.
- На крупном масштабе случайное расположение даёт ≈ 50 %, не 0.
- Автоматический поиск поверхностей надёжен на оптике (металл светлее заливки);
  на СЭМ после фильтра — через `--surface-guess`.
