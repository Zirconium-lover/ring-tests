# hydrides/ — гидриды на снимках сечения стенки

`hydride_spec.py` — анализ снимка поперечного сечения стенки (оптика или СЭМ):
ориентация гидридов **по масштабам**, профили по толщине, связность через стенку.
Снимки шлифов и статьи в git не кладём (репозиторий публичный) — здесь только код.

## Запуск

```bash
# оптика, масштаб известен
python hydride_spec.py снимок.jpg --um-per-px 0.862 --crop 0,1616,0,1130 --out out
# масштаб по линейке (длина линейки в пикселях ищется сама)
python hydride_spec.py снимок.jpg --bar-um 200 --out out
# поле внутри стенки или листа, поверхностей в кадре нет (ND — по вертикали)
python hydride_spec.py поле.png --um-per-px 0.641 --field --line-um 5
# СЭМ после полосового фильтра: заливка не отличается от металла —
# дать примерные строки поверхностей (наружная, внутренняя), они уточнятся сами
python hydride_spec.py снимок.png --um-per-px 0.847 --surface-guess 8,298 --scales 1.5,3,6,12 --layers 6
```

Наружная поверхность должна быть сверху (иначе `--outer bottom`). `--crop` убирает
подписи и линейку. `--ro-mm` фиксирует известный наружный радиус трубы.

Выход: `*_report.png` (9 панелей) и `*_metrics.json`.

## Что считается и как читать

1. **Развёртка.** К поверхностям подгоняются концентрические окружности, дуга
   разворачивается в полосу «дуга × глубина» (строка 0 — наружная поверхность).
2. **Сигнал гидридов** — «чёрный цилиндр»: насколько точка темнее светлого
   окружения. Не зависит от неравномерной подсветки.
3. **RHF по масштабу.** Сглаживание гауссом σ и вторые производные считаются
   одним умножением в пространстве Фурье. Направление линии берётся из
   собственных векторов матрицы вторых производных, длина — по скелету линий,
   веса по углу — как у Simon et al. (0 до 40°, 0.5 в 40–65°, 1 от 65°).
   - **Порог шума — суррогат.** Тот же снимок с перемешанными фазами спектра:
     сила всех волн та же, связных линий нет. Линия засчитывается, если она
     сильнее 99 % «линий» суррогата. Без этого зерно шума СЭМ тянет RHF к 0.4–0.5.
   - **Сравнимо с MATLAB/HAPPy** — RHF на σ, близком к видимой толщине
     гидридных линий (СЭМ ×300–500: σ = 3 мкм; оптика с разрешёнными
     пластинками: σ = 6 мкм по толщине пакета).
   - Малое σ — отдельные гидриды, большое — то, как они выстроены. RHF растёт
     с σ — радиальные элементы длинные; падает — радиальные элементы короткие
     (перемычки между окружными цепочками). На крупном масштабе остаются только
     самые сильные линии, их там мало.
   - В json также Fn (доля длины с отклонением больше 45°) и RHF по объектам
     (каждый связный гидрид — отрезок по главной оси, как в классических реализациях).
4. **Профили по толщине:** доля площади и RHF(σ) по слоям (`--layers`).
5. **Связность.** Наименьший зазор матрицы, при котором гидриды связывают две
   стороны окна (через стенку и вдоль дуги). Доля матрицы на лучшем пути
   трещины через стенку — двумя способами: по любым гидридам и **только по
   радиальным**. Второй ближе к механике: окружный гидрид окружным напряжением
   не раскрывается.
6. **Проверка спектром:** доля радиальных по углу энергии двумерного спектра
   (`spectral_Fn_thirds`). Это другой вес: длинные контрастные линии весят
   больше. Совпадает с Fn, когда длины радиальных и окружных элементов похожи.

## Проверено

Сверка RHF со снимками диссертации Lepine (Zircaloy-4, 178 ppm H), для которых
RHF посчитан в MATLAB (Simon et al.) и в HAPPy (Maric et al.), табл. 3.1.
Снимки взяты из PDF; σ = 3 мкм для СЭМ, порог по суррогату 98–99.5 %:

| снимок | MATLAB | HAPPy | здесь, σ = 3 мкм |
|---|---|---|---|
| СЭМ, 0 МПа | 0.073 | 0.074 | 0.00 (0.00–0.01) |
| СЭМ, 200 МПа | 0.595 | 0.552 | 0.63 (0.57–0.67) |
| СЭМ, 250 МПа | 0.819 | 0.714 | 0.82 (0.75–0.87) |

Оптика Cinbiz (RHF в источнике ≈ 0 / 0.5 / 1, округлённо): здесь на σ = 6 мкм
0.00 / 0.35 / 0.97.

Масштаб сверки (σ ≈ толщина линий) выбран по этим же трём снимкам — нужна
проверка на новых снимках с известным RHF. При RHF ≈ 0.07 метод даёт ≈ 0:
короткие наклонные отростки не проходят порог шума.

Синтетика (известная ориентация, без шума): все окружные — Fn ≈ 0.01–0.06 на
мелком масштабе; все радиальные — 0.95–1.0; «цепочки через стенку из
окружных игл» — 0.10 на 1 мкм и 0.99 на 8 мкм.

## Ограничения

- Травление утолщает гидриды: доля площади и связность на оптике завышены.
- Связность и доля площади зависят от порога сильнее, чем RHF: сравнивать
  снимки между собой можно, абсолютные значения — нет.
- Один снимок — это одно поле. Устойчивая доля радиальных требует окна
  ≥ 200–300 мкм (3–4 расстояния между радиальными гидридами); для сравнения
  состояний нужны несколько полей или панорама.
- На крупном масштабе случайное расположение даёт ≈ 50 %, не 0.
- Автоматический поиск поверхностей надёжен на оптике (металл светлее заливки);
  на СЭМ после фильтра — через `--surface-guess`.
