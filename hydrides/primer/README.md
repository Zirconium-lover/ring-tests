# Букварь спектров: как Фурье «видит» гидриды

`fourier_primer.py` строит шесть рисунков на синтетических «снимках» (окно 200 × 200 мкм, пиксель 0.5 мкм;
по горизонтали — дуга, по вертикали — радиус). Это пояснение к спектральной части `../hydride_spec.py`.

| рисунок | что показывает |
|---|---|
| `figs/fig1_azbuka.png` | полосы и их спектр: направление точки — поперёк полос, расстояние от центра — 1/период; резкие линии — ряд гармоник |
| `figs/fig2_orientation.png` | окружные — вертикальная полоса спектра, радиальные — горизонтальная; доля радиальных по углу энергии: 3 / 96 / 33 % при заданных 0 / 100 / 30 % |
| `figs/fig3_length_spacing.png` | ширина полосы ≈ 1/длина пластинки; пики на 1/шаг — только у упорядоченных рядов |
| `figs/fig4_no_where.png` | спектр не знает «где»: цепочки через окно и та же картинка с перемешанными фазами — один спектр (отсюда суррогат и отдельная мера связности) |
| `figs/fig5_windows.png` | скользящее окно 50 мкм: доля радиальных вдоль дуги по кусочкам |
| `figs/fig6_scales.png` | цепочки из коротких игл: мелкий масштаб — 13 % радиальных, крупный — 93 %; отсюда RHF по масштабу σ |

`python fourier_primer.py` — пересобрать рисунки. Пошаговый разбор на реальном окне снимка — `../spec_explain.py`.
