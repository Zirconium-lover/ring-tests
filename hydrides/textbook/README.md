# Учебник по модели гидридов

`book.pdf` — учебник по клеточно-кинетической модели гидридов (`../automaton`): физика, уравнения,
постановки, алгоритм, проверки, границы модели, упражнения с ответами.

Сборка:

```bash
cd figs_src && TB_DATA=<данные> ./render.sh      # рисунки (Manim CE, белый фон) → ../figs
cd .. && pdflatex book.tex && pdflatex book.tex   # T2A, babel russian
```

`figs_src/prep.py RUNS DATA` готовит данные для рисунков из расчётов сессии (поля пластинки, ореолы,
стопки, структуры автомата, сверка с МКЭ); без них часть рисунков не собрать — готовые PNG лежат в `figs/`.
