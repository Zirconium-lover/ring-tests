# Клеточный автомат зарождения гидридов

Сечение стенки (плоскость ND–TD, то есть радиус × дуга). Новые пластинки δ-гидрида
зарождаются одна за другой там, где это выгоднее всего с учётом:

- **упругого поля уже выросших пластинок.** Гидрид больше металла по объёму:
  несоответствие 7.2 % по нормали к пластинке и 4.6 % в её плоскости. Поле
  напряжений от всех пластинок считается через Фурье — это микроупругость
  Хачатуряна, та же, что в моделях фазового поля;
- **текстуры.** Зёрна — ячейки Вороного, вытянутые вдоль TD. В каждом зерне
  наклон следа пластинки ±χ₀ со случайным разбросом;
- **приложенного окружного напряжения при охлаждении.** Оно выбирает
  ориентацию пластинки (работа над частью несоответствия, зависящей от
  ориентации). Перераспределение водорода в растянутую зону берётся по
  Горскому и мало (±2 % при ±200 МПа).

Пластинка растёт по своей плоскости до границы зерна, до соседней пластинки или
до 6 мкм. Каждая пластинка забирает водород из окрестности радиусом
ℓ ≈ 35 мкм: поле доступного водорода истощается, и зарождаться там всё труднее.
Счёт идёт, пока доля гидрида не дойдёт до заданной (≈1.1 % ≈ 180 wppm).

## Инструмент: материал + история → гидридная структура

```python
from tool import MATERIALS, Texture, History, Model, simulate
r = simulate(MATERIALS["E635"], Texture(chi0=38.5), History(H_ppm=200, T_max=430, sigma=150))
r["metrics"]["RHF_image"]          # и packet_RHF, шаг пакетов, температура первой/средней пластинки
r["thermo"]                         # растворилось / осталось, температуры растворения и начала выпадения
```

- **Материал** (`Material`): линии растворимости (по умолчанию Э635 по Плясову и др. 2023;
  TSSD у циркониевых сплавов одна), σ_y(T), упругие константы.
- **Текстура** (`Texture`): χ₀ или профиль по толщине, разброс, размер зёрен.
- **История** (`History`): водород, T_max, окружное напряжение (и изгиб), конечная температура.
- **Модель** (`Model`): по умолчанию — пластический вклад нагрузки из МКЭ (`app="iso2d"`, Δg ≈ σθ),
  калибровка по Lepine и Cinbiz: β = 0.08 1/МПа, потолок ближнего поля 240 МПа, ℓ = 35 мкм.
  Прежний упругий вариант — `Model(app="el", beta=0.12, sigma_cap=90)`. По выбору β ∝ 1/T
  и потолок ∝ σ_y(T) от температуры выпадения.

`thermo.py` переводит долю выпавшего гидрида в температуру по линии TSSP, так что у каждой
пластинки есть температура выпадения. Если T_max ниже TSSD, часть водорода не растворяется:
эти гидриды остаются из исходной (окружной, без напряжения) структуры, и новые выпадают рядом с ними.

`trends.py` и `trends_report.py` — проверка на общие закономерности, а не на один опыт:
порог переориентации от водорода (ориентир — Desquines и др. 2014) и неполное растворение.

Первая проверка (упругий вариант; Zry-4, χ₀ = 30°, 2 затравки, рис. `figs/fig7_trends_el.png`):

| закономерность | опыт | инструмент |
|---|---|---|
| RHF без напряжения | ≈ 0.07 | 0.05–0.15 ✓ |
| рост RHF с T_max при неполном растворении | есть | 250 МПа: 0.33 (350 °C) → 0.69 (420 °C) ✓ |
| порог растёт с водородом и выходит на полку | 149 → 175 МПа (60–450 ppm) | β и потолок постоянны: 40 → 65 → ≈ 80–100; с β ∝ 1/T и потолком ∝ σ_y(T): ≈ 75–97 без роста |
| величина порога | ≈ 150–175 МПа | вдвое ниже ✗ |
| резкость перехода | RHF от ≈ 0.1 до ≈ 0.6 на ≈ 50 МПа | на ≈ 150 МПа ✗ |

Учёт температуры выпадения (β ∝ 1/T, потолок ∝ σ_y(T)) рост порога с водородом не даёт.
Главное, чего не хватает инструменту, — величины и резкости порога.

**Кинетический движок** (`ca_kinetic.py`, `Model(engine="kin")`, рис. `figs/fig8_trends_kin.png`): время
и охлаждение, растворённый водород диффундирует с D(T), зародыши одного шага возникают одновременно
и друг друга не видят, скорость зарождения — по классической теории относительно линии TSSP.
Выпадение идёт вдоль TSSP само (первая пластинка при 321 °C для 178 ppm), водородный баланс сходится.
Калибровка по Lepine: B = 80, Δ0 = 15 МПа, потолок 180 МПа (ошибка 0.08 против 0.05 у движка
«по одной»). Проверка на закономерностях хуже: порог 33–78 МПа, при 60 ppm RHF без напряжения 0.37,
скорость охлаждения 1–30 °C/мин почти не влияет; неполное растворение — верно. Пакеты получаются
короткими: обеднение водородом вокруг пластинки сильнее упругого притяжения к её кончикам.
Одновременность зарождения сама по себе резкого порога не даёт.

**Среднее поле без потолка** (`Model.cap_local_only`, теперь по умолчанию в `tool.py`). Окружные гидриды
сжаты вдоль окружности (≈ −3 ГПа внутри), и металл в среднем растянут по окружности и сжат по радиусу:
+12 / −11 МПа при 180 ppm, +23 / −21 МПа при 700 ppm. По выгоде это как внешнее окружное напряжение
≈ 20 и ≈ 45 МПа. Прежний потолок 90 МПа обрезал это поле вместе с ближним полем у кончиков; теперь
потолок только на ближнее поле. Проверка по Исаенковой и др. 2023 (трубы Э635 без напряжения,
`trends_e635.py`, χ₀ = 38.5°, 3 затравки):

| H, ppm | 100 | 300 | 500 | 700 |
|---|---|---|---|---|
| потолок на всё поле | 0.22 | 0.19 | 0.21 | 0.20 |
| потолок на ближнее поле | 0.23 | 0.24 | 0.24 | 0.30 |
| опыт, RHC | 0.10 | 0.12 | 0.16 | 0.18 |

Рост с водородом появляется (+0.07 против +0.08 в опыте); уровень завышен на ≈ 0.1 — двумерная
текстура χ₀ = 38.5° ± 26° даёт слишком много крутых зёрен. Калибровка по Lepine не портится, переход
немного резче: RHF 0.08 / 0.39 / 0.53 / 0.65 / 0.71 при 0 / 100 / 150 / 200 / 250 МПа (было
0.10 / 0.46 / 0.62 / 0.66 / 0.70).
Порог (RHF = 0.35) от водорода с новым умолчанием: 69 / 79 / 103 / 81 / 85 МПа при 60 / 100 / 180 / 300 /
450 ppm (было 40 / 65 / 102 / 79 / 87; опыт Desquines 149–175). Рост на малом водороде стал ровнее,
но порог по-прежнему вдвое ниже опыта.

**Перепроверка с пластическим вкладом нагрузки** (новое умолчание: `app="iso2d"`, β 0.08, потолок 240;
`trends.py`, `trends_e635.py`, рис. `figs/fig7_trends.png`; прежний — `figs/fig7_trends_el.png`):

| закономерность | опыт | упругий вариант | пластический вариант |
|---|---|---|---|
| RHF без напряжения (Zry-4) | ≈ 0.07 | 0.05–0.15 | 0.03–0.12 ✓ |
| порог (RHF 0.35) при 60 / 100 / 180 / 300 / 450 ppm, МПа | 149 / 161 / 171 / 174 / 175 | 69 / 79 / 103 / 81 / 85 | 106 / 126 / 131 / 135 / 121 |
| то же, β ∝ 1/T и потолок ∝ σ_y(T) | | ≈ 75–97 | 132 / 195 / 173 / 134 / 132 (шумно) |
| неполное растворение, 250 МПа: T_max 350 → 420 °C | рост | 0.33 → 0.69 ✓ | 0.36 → 0.64 ✓ |
| резкость: RHF от ≈ 0.1 до ≈ 0.6 | на ≈ 50 МПа | на ≈ 150 МПа ✗ | на ≈ 200 МПа ✗ |
| Э635 без напряжения, 100 / 300 / 500 / 700 ppm (RHC, Исаенкова 2023) | 0.10 / 0.12 / 0.16 / 0.18 | 0.23 / 0.24 / 0.24 / 0.30 | 0.15 / 0.20 / 0.17 / 0.24 |

Порог поднялся на 35–55 МПа и теперь ниже опыта на 20–30%, а не вдвое. Он растёт с водородом
от 60 до 300 ppm (106 → 135 МПа), как у Desquines, но при 450 ppm снова опускается. Без напряжения
уровень у Э635 стал ближе к опыту (завышение ~0.05 вместо ~0.1); рост с водородом сохранился
(+0.09 против +0.08). Резкости перехода по-прежнему нет: это главный оставшийся недостаток.

## Пилот 3D (`ca3d.py`, `pilot3d.py`, `pilot3d_image.py`, рис. `figs/fig9_pilot3d.png`)

Тот же автомат в кубе 48 мкм с периодическими границами: трёхмерные зёрна Вороного (4.5 × 2.5 × 6 мкм
по TD × ND × оси трубы), ось c по факторам Кернса (с осевым разбросом 21° — f_L ≈ 0.11, как у листа
Lepine), пластинки-диски в базисной плоскости, 3D-микроупругость. Параметры — из 2D-калибровки
(β = 0.12, потолок 90 МПа на ближнее поле, ℓ = 35 мкм). RHF — по сечениям ⊥ оси трубы, как на шлифе.

| RHF | 0 | 100 | 150 | 200 | 250 МПа | порог 0.35 |
|---|---|---|---|---|---|---|
| по следам: 2D (6 затравок) | 0.25 ± 0.09 | 0.46 | 0.56 | 0.62 | 0.63 | ≈ 50 МПа |
| по следам: 3D, ось c в сечении | 0.14 ± 0.01 | 0.35 | 0.44 | 0.59 | 0.63 | ≈ 100 МПа |
| по следам: 3D, с осевой составляющей | 0.16 ± 0.01 | 0.31 | 0.47 | 0.56 | 0.63 | ≈ 113 МПа |
| по изображению: 2D | 0.21 | 0.38 | 0.46 | 0.54 | 0.62 | ≈ 83 МПа |
| по изображению: 3D, с осевой составляющей | 0.15 | 0.30 | 0.39 | 0.47 | 0.55 | ≈ 128 МПа |

При тех же параметрах 3D сдвигает переход к большим напряжениям: порог по следам вдвое выше,
чем в 2D, RHF без напряжения ниже, разброс между затравками в разы меньше (каждое сечение
пересекает сотни дисков). При 200–250 МПа RHF по изображению в 3D ниже опыта — нужна
калибровка в 3D. Диски мелкие (радиус ≈ 0.8 мкм): в 3D пластинку ограничивает зерно со всех сторон.
Куб 48 мкм считается ≈ 3 мин; для статистики пакетов (шаг ≈ 70 мкм) нужен объём ≥ 200 мкм —
это уже суммирование полей одной пластинки вместо полного Фурье на каждом шаге.

## Калибровка 3D (`ca3d.run3d_fast`, `calib3d.py`, `sec3d.py`, рис. `figs/fig10_calib3d.png`)

**Быстрый движок.** Поле новой пластинки считается Фурье в окне 32³ клеток (16 мкм) вокруг неё.
Окно периодическое, и его решение имеет нулевое среднее по окну, а настоящее поле малого включения
нет: без поправки каждая пластинка добавляет вокруг себя ложное растяжение ≈ 2–3 МПа, пластинки
слипаются и укрупняются. Поправка: (V/W³)·M:ε*, где M (6×6) один раз считается по включению в
большом кубе (аналог леммы Танаки–Мори для кубического окна). Раз в 100 пластинок поле считается
точно по всему кубу от накопленной собственной деформации; среднее напряжение в металле — на
каждом шаге. Сверка с полным Фурье на кубе 48 мкм (по 3 затравки):

| | 0 МПа: RHF по следам / пластинок / R, мкм | 250 МПа |
|---|---|---|
| полный Фурье | 0.155 / 671–761 / 0.85–0.91 | 0.632 / 927–963 / 0.77–0.79 |
| быстрый | 0.142 / 652–715 / 0.88–0.92 | 0.627 / 921–995 / 0.76–0.78 |

Время на одно ядро: куб 48 мкм — 15–25 с (было 150–290), 64 мкм — 1–3 мин, 96 мкм — 4–7 мин,
128 мкм — 25–40 мин (пул из 4 процессов).

**Размер куба.** В отличие от 2D (поле 48 мкм: RHF без напряжения от 0.17 до 0.41 между затравками,
против 0.15 на 240 мкм), в 3D RHF по следам от размера не зависит: 0.13–0.16 / 0.60–0.67 при
0 / 250 МПа для кубов 48, 96 и 128 мкм. Шаг окружных пакетов на сечении при этом равен размеру куба.

**RHF по изображению** сечения в 3D сильно шумит: от сечения к сечению ±0.15–0.25, потому что
следы дисков короче 2 мкм. Берётся среднее по 32 сечениям на куб.

**Перебор** β = 0.12…0.5 и потолка 30…250 МПа при 0 / 200 / 250 МПа (куб 64 мкм, по две затравки;
числа — `figs/calib3d_numbers.json`):

| β, потолок | RHF по следам: 0 / 100 / 150 / 200 / 250 МПа | по изображению: 0 / 200 / 250 | угол следа при 250 МПа |
|---|---|---|---|
| 0.12, 90 (как в 2D) | 0.15 / 0.36 / 0.48 / 0.56 / 0.63 | 0.15 / 0.55 / 0.56 | 59° |
| 0.25, 65 | 0.14 / 0.49 / 0.57 / 0.62 / 0.66 | 0.17 / 0.55 / 0.55 | 61° |
| 0.25, 45 | 0.16 / 0.58 / 0.69 / 0.72 / 0.74 | 0.17 / 0.58 / 0.56 | 65° |
| 0.12, 150 | 0.16 / — / — / 0.35 / 0.43 | 0.18 / 0.34 / 0.39 | — |
| 0.12, 250 | 0.15 / — / — / 0.32 / 0.33 | 0.32 / 0.34 / 0.36 | — |
| Lepine, MATLAB | — | 0.073 / 0.595 / 0.819 | 47.7° (FIB-SEM) |
| Lepine, HAPPy | — | 0.074 / 0.552 / 0.714 | |

Что получилось:
- **Высокий потолок в 3D запирает окружные пластинки**: при потолке 150–250 МПа RHF при 250 МПа
  0.33–0.43. Линии «β·σ_cap ≈ 11», как в 2D, нет; лучше всего по следам — β 0.18–0.35 при потолке
  45–65 МПа (ошибка 0.08 против 0.09 у параметров 2D).
- **Без напряжения RHF не опускается ниже 0.14** ни при каких β и потолке — это задаёт текстура
  (у Lepine 0.07).
- **RHF по изображению упирается в 0.55–0.58** при любых β и потолке. На сечении при 250 МПа видны
  отдельные пятна — диски по 1–2 мкм, а не длинные радиальные пакеты, как в 2D (рис., нижний ряд).
  Увеличение минимального радиуса диска до 1–1.5 мкм RHF по изображению не поднимает (0.47–0.50).
- **Пластинки в модели круче, чем в опыте.** По FIB-SEM Lepine (разд. 3.3.2) пластинки в радиальных
  пакетах наклонены в среднем на 47.7° к TD и уложены «колодой карт» вдоль радиуса. Высокий RHF опыта
  даёт ориентация пакета, а не отдельной пластинки. В модели при 200–250 МПа средний угол следа
  56–65°, и подгонка по следам делает пластинки ещё круче — это неверная цель.

Вывод: в 3D β и потолок двигают ориентацию отдельных пластинок, но радиальные пакеты из наклонных
пластинок («колода карт») сами не возникают. В 3D пластинка у кромки соседа может зародиться в любом
направлении своей плоскости (зёрна вдоль оси трубы длиннее, 6 мкм против 2.5 мкм по радиусу), и пакет
расползается вдоль оси, а не вдоль радиуса. Параметры по умолчанию не меняются (β 0.12, потолок 90
МПа на ближнее поле). Цели для 3D по FIB-SEM Lepine (табл. 3.3, рис. 3.12–3.27):
- окружной пакет непрерывен по RD на ≥ 7–12.6 мкм и по TD через весь объём (13–26 мкм), толщина по
  ND 3.8–4.9 мкм;
- в радиальном пакете пластинки толщиной 1–3.4 мкм (медиана 1.66) под углом 47.7° к TD, ветвистая
  сеть, «колода карт» по ND и RD.

## Карта притяжения в 3D (`map3d.py`, рис. `figs/fig11_map3d.png`)

Поле одной пластинки (диск ∅ 3 мкм, толщина 0.6 мкм, нормаль в плоскости r–θ, след под ψ к TD) и
выгода g зарождения следующей — параллельной (∥) или зеркальной (−ψ, зигзаг). Для сравнения та же
пластинка в 2D (бесконечная вдоль оси трубы). Привлекательность места — exp(β·min(g, 90)) − 1 в шаре
4.5 мкм вокруг пластинки, как в автомате; числа — `figs/map3d_numbers.json`.

| следующая | 2D: куда идёт цепочка в r–θ | 3D-диск: куда в r–θ, доля вдоль оси трубы |
|---|---|---|
| ψ 20°, ∥ | 20° | 21°, 49% |
| ψ 20°, −ψ | 3° | 6°, 57% |
| ψ 48°, ∥ | 47° | 47°, 50% |
| ψ 48°, −ψ | 69° | в сечении r–θ притяжения нет, 100% вдоль оси |
| ψ 70°, ∥ | 70° | 69°, 49% |
| ψ 70°, −ψ | 87° | 84°, 57% |

(0° — цепочка по окружности, 90° — по радиусу.)

- **Параллельная пластинка.** В 2D выгодны два кончика, в 3D — всё кольцо вокруг кромки. Поле диска
  осесимметрично относительно его нормали, поэтому половина притяжения уходит вдоль оси трубы.
  Пластинка разрастается в плоский лист в своей плоскости: пластинки под 48° дают лист под 48°, а не
  радиальную «колоду карт».
- **Зигзаг (−ψ)** — механизм радиальных цепочек в 2D при ψ > 45° — в 3D для 48° работает только вдоль
  оси трубы: в сечении r–θ притяжения нет. Для 70° радиальный зигзаг сохраняется (84°), но 57%
  притяжения уходит вдоль оси.
- **Вытянутость пластинки вдоль оси** (лента) возвращает притяжение в сечение r–θ: при вытянутости
  ×8 доля вдоль оси 0.29–0.33, а зигзаг под 48° идёт по радиусу (66°). Но по FIB-SEM Lepine
  пластинки в радиальных пакетах при взгляде по нормали — округлые пятна (рис. 3.27), а не ленты.

Вывод: в 3D упругое взаимодействие круглых пластинок в базисной плоскости не собирает радиальную
«колоду карт» из пластинок под ~48°. Радиальные пакеты 2D-автомата отчасти получаются потому, что в
2D пластинка бесконечна вдоль оси трубы; к тому же в них пластинки круче (58–67°), чем на снимках
(47–52°). Для 3D нужен механизм, который не сводится к осесимметричному полю одной пластинки:
поле пакета целиком (мезомасштаб), анизотропная пластичность у кромки, габитус {10-17} вместо
базиса.

## Кристаллография микрогидрида в 3D (`P3(shape="needle")`, первый шаг)

По литературе (Carpenter; Perovic et al.; Han et al. 2019; Patel et al. 2021; Fang et al. 2017):
- ориентационное соотношение {111}δ ∥ (0001)α, ⟨110⟩δ ∥ ⟨11-20⟩α; несоответствие δ-гидрида в осях
  кристалла — 7.2 % вдоль c и 4.58 % в базисной плоскости, от габитуса не зависит;
- **микрогидрид** — вытянутая пластинка (игла) в базисной плоскости, длинная ось вдоль одного из трёх
  ⟨11-20⟩, длина 1–5 мкм (Patel);
- **макрогидрид** — «колода карт» из микрогидридов на соседних базисных плоскостях, отсюда видимый
  габитус {10-17}, 14.7° от базиса (Perovic; Han);
- нормали пластинок в 3D группируются около полюса {0002}, пластинки проходят через границы зёрен,
  межзёренные гидриды подчиняются другим ориентационным соотношениям (Fang, томография DCT);
- у листа Lepine (CW Zircaloy-4) одно направление ⟨10-10⟩ ∥ направлению прокатки (оси трубы), поэтому
  оси ⟨11-20⟩ лежат под 30°, 90° и 150° к оси; у рекристаллизованного металла ⟨11-20⟩ ∥ оси.

Что сделано в `ca3d.py`:
- **полная ориентация зерна**: ось c (как раньше) + поворот вокруг неё (`prism` = "10-10" (CWSR),
  "11-20" (RX) или "random", разброс `prism_s`);
- **пластинка-игла**: эллипс в базисной плоскости, длинная ось вдоль ⟨11-20⟩. Растёт вдоль оси в обе
  стороны до границы зерна, соседа или 6 мкм, затем в ширину до 1 мкм;
- **выбор варианта** из трёх ⟨11-20⟩ — с вероятностью ∝ exp(β·ḡ), где ḡ — средняя выгода вдоль длины
  иглы (взаимодействие формы с полем соседей). Приложенное напряжение одинаково для всех трёх
  вариантов, потому что несоответствие δ изотропно в базисной плоскости;
- сечения и RHF (`plate_chord`, `sec3d`) считают следы эллипсов; для дисков дают прежний результат.

Первый результат (куб 64 мкм, CWSR, β 0.12, две затравки):

| | 0 МПа | 200 МПа | 250 МПа |
|---|---|---|---|
| RHF по следам (иглы / диски) | 0.19 / 0.15 | 0.57–0.64 / 0.56 | 0.62–0.68 / 0.63 |
| RHF по изображению (иглы / диски) | 0.27–0.32 / 0.15 | 0.45–0.47 / 0.55 | 0.46–0.51 / 0.56 |
| средний угол следа, иглы | 31° | 56–60° | 58–62° |

Иглы получаются короткими (длина 1.2–1.5 мкм, ширина 0.5 мкм, ~6000 на куб) и **в пакеты не
собираются**: на сечении r–θ — рассыпанные точки (иглы почти вдоль оси трубы режутся поперёк), даже
без напряжения нет окружных полос, которые давали диски. Причина — масштаб: в автомате пластинка
толщиной 0.6 мкм на сетке 0.5 мкм с зазором 0.5 мкм, а настоящие микрогидриды тоньше 0.1 мкм и лежат
в «колоде» через доли микрона. Плотную «колоду карт» на этой сетке не разрешить.

Следствие: в 3D нужна двухуровневая модель — единица автомата не микрогидрид, а **отрезок
макрогидрида в зерне** (стопка игл): плоскость {10-17} (6 вариантов на зерно — 3 оси ⟨11-20⟩ × 2
направления ступенек), форма — сечение зерна этой плоскостью, несоответствие — среднее по стопке
в осях кристалла. Плюс межзёренные отрезки и переход через границу.

## 3D с отрезками макрогидрида на {10-17} (`P3(shape="segment")`, рис. `figs/fig12_seg3d.png`)

Единица автомата — **отрезок макрогидрида в зерне**: стопка микрогидридов-игл, видимая как пластинка
на плоскости {10-17}.
- **Шесть вариантов на зерно**: ось c, повёрнутая на ±14.7° вокруг каждой из трёх осей ⟨11-20⟩
  (иглы вдоль u, ступеньки в одну или другую сторону). Угол 14.7° — из c/a = 1.593, не подбирается.
- **Форма** — часть плоскости габитуса через зародыш, лежащая в том же зерне, свободная и связная с
  зародышем (заливка по клеткам), не дальше 4 мкм от зародыша. Кругов нет: отрезок — сечение зерна.
- **Несоответствие** — δ-гидрида в осях кристалла (7.2 % вдоль c, 4.58 % в базисе), доля гидрида в
  отрезке 1, как у пластинок в 2D. Поэтому приложенное напряжение одинаково для всех шести вариантов
  зерна: оно выбирает зёрна, а вариант выбирает поле соседей.
- **Выбор варианта** — с вероятностью ∝ exp(β·ḡ), ḡ — средняя выгода по клеткам отрезка.
- Клетки каждого отрезка сохраняются (`cells`, `cfr`, `cptr` в npz) — это готовая 3D-геометрия.

Как измеряется (одинаково для дисков и отрезков):
- **RHF по следам** — по площади пластинок, вес — площадь × синус угла к сечению.
- **RHF по изображению** — по срезам поля гидрида, как `image_rhf` в 2D. Прежний способ (рисовать
  следы линиями) на мелких редких пятнах неустойчив: на одном и том же сечении дисков 0.57 против 0.76
  в зависимости от контраста, по одному сечению — от 0.3 до 0.9. Поэтому прежняя оценка «RHF по
  изображению упирается в 0.55» относится к способу измерения.
- **Пакеты** — на сечениях r–θ тем же способом, что в 2D (`ca_analysis.clusters`, зазор 1 мкм), и в 3D
  (`packets3d`: связные области с зазором 1 мкм, протяжённость по TD, ND и оси трубы).

## Межзёренные отрезки и переход через границу (`P3(gb=..., gb_eps=..., cross_deg=...)`, рис. `figs/fig13_gb3d.png`)

Основание: Fang et al. 2017 (томография DCT) — пластинки проходят сквозь границы зёрен, межзёренные гидриды
имеют другие ориентационные соотношения; Исаенкова и др. (JMEP) — пластинки поперёк растяжения образуются
легче или труднее «в зависимости от подходящим образом ориентированных границ зёрен».

- **Грани зёрен** (`grain_facets`): пары соседних зёрен, плоскость грани (главные оси точек на границе),
  площадь и клетки по обе стороны. У зёрен 4.5 × 2.5 × 6 мкм 46 % площади граней — с нормалью ближе 30°
  к ND (окружные), 8 % — к TD (радиальные), 3 % — к оси трубы.
- **Межзёренный отрезок** (`gb=True`) зарождается на клетке грани и лежит в её плоскости в обоих зёрнах.
  Вес зарождения на грани — как в теле зерна, умноженный на `w_gb` (по умолчанию 1: граница не выгоднее).
  Несоответствие — **допущение** `gb_eps`:
  - `"facet"`: 7.2 % по нормали к грани, 4.58 % в её плоскости ({111}δ ∥ границе);
  - `"grain"`: в осях того из двух зёрен, чья ось c ближе к нормали грани (плоскость гидрида ∥ {0002}
    соседнего зерна — Fang).
- **Переход через границу** (`cross_deg`): отрезок {10-17} продолжается в соседнее зерно, если у того есть
  вариант {10-17} с нормалью ближе `cross_deg` (15°, допущение); в каждом зерне несоответствие — в осях
  его кристалла.

Результат (куб 64 мкм, β 0.12, потолок 90 МПа — как в 2D, по две затравки), RHF по изображению:

| вариант | 0 МПа | 100 | 150 | 200 | 250 МПа | доля на границах | угол следа при 250 МПа |
|---|---|---|---|---|---|---|---|
| отрезки в теле зерна | 0.14 | 0.37 | 0.52 | 0.62 | 0.60 | 0 | 61° |
| + переход через границу | 0.17 | 0.35 | 0.52 | 0.59 | 0.57 | 0 (56–72 % отрезков в 2+ зёрнах) | 62° |
| + межзёренные, `grain` | 0.17 | 0.39 | 0.46 | 0.53 | 0.57 | 0.39–0.45 | 54° |
| + межзёренные, `facet` | 0.15 | 0.55 | 0.66 | 0.74 | 0.78 | 0.43–0.51 | 68° |
| + межзёренные `facet` + переход | 0.12 | 0.41 | 0.66 | 0.74 | 0.79 | 0.38–0.49 | 69° |
| Lepine | 0.07 | | | 0.55–0.60 | 0.71–0.82 | | 47.7° (FIB-SEM) |

Что получилось:
- **Переход через границу** укрупняет отрезки и даёт больше длинных окружных пакетов без напряжения
  (6–12 пакетов от 15 мкм на 16 сечений против 1–3), но RHF не меняет.
- **Межзёренные отрезки целиком зависят от допущения о несоответствии.** С несоответствием по нормали
  к грани окружное напряжение выбирает радиальные грани, и RHF при 250 МПа совпадает с Lepine (0.78–0.79),
  а без напряжения ниже (0.12). Но переход начинается раньше опыта (при 200 МПа 0.74 против 0.55–0.60),
  и радиальность даётся крутыми пластинками на гранях (средний угол 68–69°), а не «колодой карт» из
  пластинок под 48°, как на FIB-SEM. С несоответствием в осях соседнего зерна межзёренные отрезки ничего
  не меняют (0.57 при 250 МПа), зато пластинки ближе к опыту (54°).
- Без преимущества границы на неё выпадает 40–50 % гидрида при любом напряжении — это прогноз модели.

Что нужно из опыта, чтобы выбрать: ориентационное соотношение межзёренных радиальных гидридов
(EBSD: {111}δ ∥ границе или ∥ {0002} соседнего зерна) и доля межзёренных гидридов в металле. Пока это
не известно, оба варианта остаются опциями, по умолчанию межзёренные отрезки выключены.

## Двухосность напряжения и что говорит обзор Motta et al. 2019 (`P3(sigma_axial=...)`)

Обзор Motta et al., J. Nucl. Mater. 518 (2019) 440 — вопросы, которые остаются открытыми (разд. 7):
- **как образуются мезоскопические гидриды** длиной ~100 мкм при зерне в 1–2 мкм — «обычные объяснения
  (ориентационное соотношение и текстура, ориентация границ зёрен) могут дать начальные гидриды, но не
  длинные»; две гипотезы — анизотропный рост или зарождение у кромки существующего гидрида;
- **почему напряжение переориентирует гидриды**: под нагрузкой следующий гидрид садится не у кромки
  (позиция 1 на рис. 30), а над ним (позиция 3), и радиальный гидрид при большом увеличении — это
  стопка горизонтальных отрезков (разд. 4.2, рис. 15);
- переориентация одиночного нанодиска в фазовом поле требует ~900 МПа — в 10 раз больше 85 МПа опыта,
  то есть переориентация — коллективное явление;
- дислокации, испущенные гидридом, — места зарождения новых (FFT-ДД, Tummala; рис. 26), и «колода карт»
  под ~14° может быть следствием этой релаксации.

**Проверка двухосностью.** Порог переориентации при 200 ppm падает с ~155 МПа при одноосном растяжении до
~80 МПа при почти равнодвухосном (Cinbiz; рис. 13 обзора). В модели осевое напряжение не различает
радиальные и окружные пластинки: обе содержат ось трубы, и вклад σ_z·ε*_zz у них одинаков. Расчёт (отрезки
{10-17}, куб 48 мкм, σ_θ = 150 МПа, три затравки): RHF по следам 0.54 / 0.51 / 0.54 при σ_z/σ_θ = 0 / 0.5 /
0.8 — эффекта нет, в опыте при 150 МПа и двухосности 0.5–0.8 переориентация уже полная. Это та же
структурная причина, что и отсутствие радиальных стопок: в однородной линейной упругости приложенное
напряжение выбирает только ориентацию новой пластинки, но не её место относительно соседей. Недостающий
механизм должен связывать приложенное напряжение с полем существующих гидридов — пластичность и
дислокации у кромки, различие упругих модулей гидрида и матрицы, перенос водорода к растянутым местам.

**Смысл β.** Вес зарождения exp(β·g) — больцмановский множитель для энергии взаимодействия зародыша
объёмом V: β = ε_n·V/kT. При β = 0.12 1/МПа и T ≈ 600 K это V ≈ 14 нм³ (диск радиусом ~3 нм) — порядок
критического зародыша; β можно проверять независимо (атомистика, теория зарождения).

## Экранирование приложенного напряжения у гидридов (`Params(screen=True)`, рис. `figs/fig14_screen.png`)

Из МКЭ (`fe/biax_inh.py`): в пластической зоне у существующей пластинки приложенное напряжение почти
не влияет на выбор ориентации новой. Доля действия нагрузки от расстояния до гидрида (пластинка
5 × 0.6 мкм, σ_y = 350 МПа; одинаково при 155 / 0, 110 / 0.57 и 75 / 0.83): 0.05–0.1 ближе 1 мкм,
~0.45 на 1–2 мкм, ~0.7 на 2–3 мкм, 1 дальше 3 мкм. В 2D-автомате вклад приложенного напряжения
умножается на эту долю по расстоянию до ближайшего гидрида (`screen_scale` — масштаб зоны).

Поле 240 мкм, β 0.12, потолок 90 МПа, ℓ 35 мкм (как в калибровке, без изменений), две затравки:

| RHF по изображению | 0 | 50 | 100 | 125 | 150 | 175 | 200 | 250 МПа |
|---|---|---|---|---|---|---|---|---|
| без экранирования | 0.08 | 0.28 | 0.39 | 0.47 | 0.53 | 0.66 | 0.65 | 0.71 |
| экранирование, зона ×0.5 | 0.08 | 0.28 | 0.36 | 0.47 | 0.47 | 0.56 | 0.59 | 0.67 |
| экранирование по МКЭ | 0.08 | 0.16 | 0.28 | 0.43 | 0.38 | 0.51 | 0.52 | 0.59 |

Экранирование сдвигает кривую к большим напряжениям, но не делает переход резким, а при 250 МПа
опускает RHF ниже опыта. У Cinbiz при одноосном растяжении RHF растёт от 0 до ~1 между 145 и 177 МПа.
Наклон кривой в автомате задаёт избирательность одного зарождения: шансы «радиальная против окружной»
растут как exp(β·0.36·Δσ), за 30 МПа — всего в 3.7 раза при β = 0.12, а для перехода 0 → 1 нужно
в сотни раз. Экранирование уменьшает число зародышей, которые видят нагрузку, но не делает каждый
избирательнее. Резкий порог требует β ≈ 0.4–0.8 1/МПа, то есть объёма зародыша ~50–100 нм³ вместо ~14
(β = ε_n·V/kT) — например, согласованного зарождения стопки микрогидридов. По умолчанию экранирование
выключено. Перебор в следующем разделе это
предположение не подтвердил: больший β порога не даёт.

## Перекалибровка β и потолка по Lepine и Cinbiz (`calib_beta.py`, рис. `figs/fig15_beta.png`)

Две мишени:
- Lepine — RHF по изображению 0.07 / 0.57 / 0.77 при 0 / 200 / 250 МПа;
- Cinbiz et al. 2016 — при одноосном растяжении доля длины гидридов под 45–135° равна 0 до 145 МПа
  и ~1 выше 177 МПа (CWSR Zircaloy-4, лист, два цикла охлаждения под нагрузкой, 1 °C/мин).

На снимке модели (0.65 мкм/пкс, размытие 1 мкм, шум) измеряются те же величины: RHF по изображению
и доля длины под 45–135° на масштабе 3 мкм (Fn45). Ошибка — СКО отдельно по каждой мишени.

Перебор: поле 240 мкм, ℓ 35 мкм, две затравки, σ 0–250 МПа:
- β 0.12–0.6 при потолке 40–90 МПа;
- β 0.3–0.6 при потолке 120–220 МПа;
- β 0.3–0.6 при потолке 90 и 160 МПа с экранированием по МКЭ;
- дополнительные точки 25 / 50 / 75 МПа.

Сводка — `calib_beta_report.py`.

| Fn45 на снимке | 0 | 25 | 50 | 75 | 100 | 150 | 175 | 250 МПа | ошибка Lepine / Cinbiz |
|---|---|---|---|---|---|---|---|---|---|
| Cinbiz 2016 | 0 | 0 | 0 | 0 | 0 | ~0.05 | ~0.95 | ~1 | |
| β 0.12, потолок 90 | 0.11 | 0.17 | 0.35 | 0.54 | 0.49 | 0.65 | 0.78 | 0.84 | **0.055** / 0.38 |
| β 0.6, потолок 90 | 0.19 | — | — | — | 0.70 | 0.66 | 0.70 | 0.66 | 0.13 / 0.47 |
| β 0.6, потолок 220 | 0.09 | — | — | — | 0.30 | 0.29 | 0.24 | 0.35 | 0.33 / 0.48 |
| β 0.3, потолок 90, экранирование | 0.15 | — | 0.27 | — | 0.40 | 0.52 | 0.62 | 0.67 | 0.13 / 0.35 |

Что получилось:
1. **Порога нет ни в одном варианте.** При β 0.12 и потолке 90 МПа доля радиальной длины уже 0.17
   при 25 МПа и 0.35 при 50 МПа; у Cinbiz — 0 вплоть до 145 МПа. Причина в устройстве выбора.
   Шансы «радиальная против окружной» растут как exp(β·Δg), а Δg = 0.36·σ пропорциональна нагрузке.
   Перевес появляется при любом σ > 0, и в модели нет ничего, что держало бы его до порога.
2. **Больший β не делает переход резче на снимке.** Отдельные пластинки при β 0.6 почти все крутые
   уже при 100 МПа: доля длины пластинок под 45–135° равна 0.85. Но на снимке доля упирается в 0.6–0.7:
   крутые пластинки из соседних зёрен собираются в пакеты, которые на масштабе 3 мкм частью идут
   вдоль окружности. Без нагрузки RHF вырастает до 0.15–0.3 против 0.07 в опыте.
3. **Больший потолок опускает плато.** При потолке 220 МПа плато падает до 0.25–0.35: сильное
   ближнее поле запирает гидрид в окружных стопках.
4. **Экранирование по МКЭ при большом β сдвигает кривую вправо, но порога не даёт.** Первые
   пластинки в каждой области зарождаются вдали от гидридов и видят полную нагрузку.
5. **Мишени между собой не вполне согласны.** У Lepine при 200 МПа RHF 0.57, у Cinbiz при 177 МПа
   ~1. Разница в метрике этого не объясняет: в модели Fn45 выше RHF по изображению всего на ~0.1.
   Значит, различаются материалы и режимы.

Итог: β 0.12 и потолок 90 МПа остаются — по двум мишеням вместе это лучшая пара (ошибка 0.27,
по Lepine 0.055). Объём зародыша β·kT/ε_n ≈ 14 нм³ при 600 К. Резкий порог Cinbiz перебором β
и потолка не получить. Для него нужна добавка, которая не зависит от σ и даёт окружной ориентации
перевес, равный выигрышу от нагрузки при ~150 МПа. В единицах g это Δg₀ ≈ 0.36·150 ≈ 55 МПа,
то есть ~7 kT на зародыш при β 0.12. Кандидаты (в модели их пока нет):
- анизотропия пластичности текстурованного металла (Хилл или кристаллическая пластичность):
  энергия аккомодации несоответствия зависит от ориентации пластинки относительно текстуры.
  Та же анизотропия нужна и для эффекта двухосности (раздел выше), так что одна поправка может
  объяснить оба эффекта;
- межзёренные остаточные напряжения от анизотропии теплового расширения и прокатки;
- зародыши на месте прежних окружных гидридов («память»; у Cinbiz два цикла).

Без такой добавки инструмент даёт пологую кривую «как у Lepine» и не предсказывает порог.

## Пластический вклад нагрузки и анизотропия по Хиллу (`fe/hill_fft.py`, рис. `fe/figs/fig_fe6_hill.png`, `figs/fig16_plast.png`)

Проверка первого кандидата из предыдущего раздела — анизотропии пластичности текстурованной
оболочки (критерий Хилла, коэффициенты Massih). Подробности — в `fe/README.md`, раздел «Анизотропия
пластичности по Хиллу».

Свой решатель упругопластичности на Фурье, сверенный с CalculiX (расхождение 0.2–7%), считает работу
выделения окружной и радиальной пластинки под нагрузкой. Мера — Δg = g_рад − g_окр:

| σθ / σz, МПа | 0 | 75 | 155 | 250 | 75 / 62 |
|---|---|---|---|---|---|
| упругость (как было в автомате) | 0 | 27 | 56 | 91 | 27 |
| Мизес, 2D / 3D | 0 / 0 | 78 | 157 / 135 | 224 | 78 |
| Хилл, 2D / 3D | −2.5 / +79 | 76 | 156 / 217 | 237 | 75 / 140 |

- **Порога и двухосности анизотропия Хилла не даёт.** В 2D сдвиг нулевой по симметрии плоской
  деформации. В 3D сдвиг обратный: +79 МПа в пользу радиальной, потому что окружной пластинке
  нужно утонение матрицы по радиусу — самое трудное для этой текстуры направление. Осевое
  напряжение меняет Δg на 1–6 МПа. Пластинка сравнима с зерном, так что, вероятно, нужен уровень
  кристаллической пластичности, а не усреднённой текстуры.
- **Пластичность втрое усиливает выбор нагрузкой:** Δg ≈ 1.0·σθ в 2D и 0.87·σθ в 3D против 0.36·σθ
  в упругости. Окружное напряжение почти не совершает работы на расширении окружной пластинки
  вдоль θ, потому что оно снимается течением. На радиальной пластинке та же нагрузка действует
  по нормали, где несоответствие снимается упруго. Это не подгонка, а результат МКЭ, и он
  переносится в автомат таблицей (`Params.app_dg`, `fe/hill_table.json`, в `tool.py` — `Model.app = "iso2d"`).

Перекалибровка с пластическим вкладом (`calib_beta.py` с `"app": ["iso2d"]`; ℓ 35 мкм, две затравки):

| Fn45 на снимке | 0 | 100 | 125 | 150 | 175 | 200 | 250 МПа | ошибка Lepine / Cinbiz / вместе |
|---|---|---|---|---|---|---|---|---|
| упругий, β 0.12, потолок 90 | 0.11 | 0.49 | 0.60 | 0.65 | 0.78 | 0.77 | 0.84 | 0.055 / 0.38 / 0.27 |
| пластический, β 0.08, потолок 180 | 0.04 | 0.64 | 0.75 | 0.78 | 0.77 | 0.81 | 0.84 | 0.074 / 0.46 / 0.33 |
| **пластический, β 0.08, потолок 240** | 0.04 | 0.31 | 0.35 | 0.50 | 0.60 | 0.71 | 0.79 | 0.077 / 0.30 / **0.22** |
| пластический, β 0.08, потолок 300 | 0.08 | 0.10 | 0.21 | 0.28 | 0.33 | 0.45 | 0.58 | 0.21 / 0.37 / 0.30 |
| пластический, β 0.2, потолок 240 | 0.12 | 0.32 | 0.34 | 0.36 | 0.49 | 0.57 | 0.62 | 0.16 / 0.33 / 0.26 |

RHF по изображению при β 0.08 и потолке 240: 0.04 / 0.26 / 0.38 / 0.58 / 0.64 при 0 / 100 / 150 / 200 / 250 МПа
(Lepine: 0.07 / — / — / 0.57 / 0.77).

- **Место перехода теперь задаёт потолок ближнего поля, а не β.** При 180 МПа середина перехода
  ниже 100 МПа, при 240 — около 150–175 (как у Cinbiz), при 300 — около 230. Механизм —
  конкуренция: притяжение соседей продолжает окружные стопки, а нагрузка с наклоном ~σθ
  перебивает его, только когда сравняется с ним. Это то же, что показало экранирование в МКЭ.
- **Крутизну β не меняет:** при β 0.2–0.3 кривая на снимке не круче, а ниже (пакеты, как и раньше).
  Ступеньки Cinbiz по-прежнему нет: доля растёт от 0.3 при 100 МПа до 0.7 при 200 МПа.
- β 0.08 соответствует объёму зародыша ~9 нм³ при 600 К. Потолок 240 МПа — это эффективная
  сила притяжения соседей; при упругом наклоне её роль играл β·потолок, который был в ~2.4 раза меньше.

Итог: пластический вариант лучше обоснован (наклон из МКЭ, а не из упругой формулы) и лучше
согласуется с обеими мишенями (ошибка 0.22 против 0.27). Он ставит середину перехода у порога
Cinbiz, но ступеньку не воспроизводит, а при 250 МПа занижает RHF. По умолчанию в `tool.py`
пока остаётся упругий вариант (`Model.app = "el"`, β 0.12, потолок 90); переход на пластический —
`Model(app="iso2d", beta=0.08, sigma_cap=240)` после перепроверки закономерностей (`trends.py`).

## Порог из измеренного сдвига выпадения и форы зёрен (кинетический движок, рис. `figs/fig17_kin.png`)

Две добавки в `ca_kinetic.py`, обе в градусах, чтобы сравнивать с опытом напрямую:
- `app_dT` — сдвиг температуры выпадения на 1 МПа нормального к пластинке напряжения: σ_nn = σθ·sin²ψ.
  Берётся из опыта: **0.08 °C/МПа**, синхротрон in situ (Vizcaíno и др. 2014). Это значение заменяет
  упругий вклад нагрузки.
- `bias_dT` — фора выпадения в зёрнах с осью c по радиусу (∝ cos²ψ). Физический смысл: зёрна разной
  ориентации различаются по плотности дислокаций, а значит, и по лёгкости зарождения. Тот же опыт
  показывает разницу 5 °C даже между семействами зёрен, развёрнутыми на 20°. В холоднодеформированном
  металле (CWSR) фора должна быть больше, в рекристаллизованном — меньше.

Обе величины переводятся в движущую силу через наклон линии TSSP: n_H·Q/T, около 6 МПа/°C.

Механизм порога. Гидрид выпадает первым в тех зёрнах, где раньше достигнута температура выпадения,
и водород (D ≈ 3·10⁻¹¹ м²/с при 250 °C — десятки микрон за минуту) стекает к ним. Поэтому при каждом
напряжении выигрывает одно семейство зёрен. Нагрузка поднимает температуру выпадения в зёрнах с осью c
по окружности, и они обгоняют радиальные, когда 0.08·σθ > фора. Отсюда **порог = фора / 0.08**
и **переход за 10–25 МПа**: его ширину задаёт разброс ориентаций.

Перебор (`calib_kin.py`; Zry-4/Э635: 178 ppm, T_max 415 °C, 3 °C/мин, B 80, Δ0 15 МПа, две затравки;
сводка — `calib_kin_report.py`):

| | 0 | 100 | 140 | 150 | 160 | 175 | 200 | 250 МПа | ошибка Lepine / Cinbiz / вместе |
|---|---|---|---|---|---|---|---|---|---|
| Cinbiz, Fn | ~0 | 0 | 0 | ~0.05 | | ~0.95 | ~1 | ~1 | |
| фора 0, Fn45 | 0.08 | 0.71 | | 0.67 | | 0.67 | 0.62 | 0.60 | 0.15 / 0.49 / 0.36 |
| фора 10 °C, Fn45 | 0.04 | 0.02 | | 0.77 | | 0.73 | 0.72 | 0.67 | 0.12 / 0.31 / 0.23 |
| **фора 12.4 °C, потолок 180, Fn45** | 0.06 | 0.03 | 0.02 | 0.02 | **0.57** | 0.68 | 0.72 | 0.74 | 0.073 / 0.16 / **0.126** |
| то же, RHF по изображению | 0.05 | 0.02 | 0.01 | 0.01 | 0.45 | 0.56 | 0.62 | 0.65 | (Lepine 0.07 / 0.57 / 0.77 при 0 / 200 / 250) |
| то же, доля радиальных пластинок | 0 | 0 | 0 | 0 | 0.56 | 0.79 | 0.99 | 1.00 | |
| фора 15 °C, Fn45 | 0.06 | 0.08 | | 0.03 | | 0.03 | 0.65 | 0.77 | 0.06 / 0.39 / 0.28 |

- **Ступенька Cinbiz воспроизводится.** До 150 МПа радиальных пластинок нет совсем, к 160 МПа их больше
  половины. Ошибка по обеим мишеням 0.126 — вдвое меньше, чем у любого прежнего варианта (0.22–0.27).
- **Подогнана одна величина — фора** (12.4 °C, чтобы порог совпал с Cinbiz). Наклон 0.08 °C/МПа взят из
  опыта, форма перехода получается сама.
- **Не решено:**
  - доля на снимке выше 0.74 не поднимается, хотя радиальны все пластинки (пакеты); отсюда занижение
    при 250 МПа (0.65 против 0.77 у Lepine) и при 177+ МПа у Cinbiz;
  - двухосность здесь не работает: осевое напряжение не входит в σ_nn для пластинок с нормалью в плоскости r–θ;
  - величину форы для CWSR нужно обосновать независимо: плотность дислокаций по ориентациям, EBSD/ПЭМ.
- Предсказание без подгонки: порог не зависит от водорода. Это согласуется с Sakamoto (61–668 ppm), но
  не с ростом у Desquines (149 → 175 МПа).

## Связность гидридов (`connectivity.py`)

Метрики, которые в литературе связывают с охрупчиванием; считаются по полю автомата или по таблице
пластинок:
- **RHLD** — плотность длины радиальных гидридов;
- **HCC** — доля толщины, перекрытая проекциями гидридов в полосе 100 мкм; HCC_rad — то же только
  по радиальным пластинкам;
- **RHCF** — самая длинная связная радиальная цепочка в долях толщины;
- **RHCP** — путь трещины наименьшей цены сквозь толщину (алгоритм Дейкстры): клетка матрицы стоит 1,
  клетка гидрида 0.05.

Связными считаются гидриды ближе 1 мкм.

Первый результат — кинетический движок, фора 12.4 °C, потолок 180 МПа, поле 240 мкм, две затравки:

| σθ, МПа | 0 | 140 | 150 | 160 | 175 | 200 | 250 |
|---|---|---|---|---|---|---|---|
| RHLD, мм/мм² | 0 | 0 | 0.03 | 10.0 | 14.1 | 17.5 | 17.7 |
| HCC_rad (среднее) | 0 | 0 | 0.00 | 0.41 | 0.52 | 0.63 | 0.69 |
| самый длинный кластер, мкм | 9 | 10 | 11 | 25 | 23 | 19 | 12 |
| RHCF (доля 240 мкм) | 0.04 | 0.04 | 0.05 | 0.11 | 0.10 | 0.08 | 0.05 |
| RHCP | 0.10 | 0.14 | 0.12 | 0.32 | 0.32 | 0.34 | 0.31 |

Метрика сразу показала слабое место модели. Радиальных пластинок под нагрузкой много: их проекции
перекрывают до 70 % толщины. Но они **не связаны**: самая длинная цепочка — 10–25 мкм, и с ростом
нагрузки она даже укорачивается (больше зародышей — короче пластинки). В опыте радиальные гидриды
длиннее и тянутся через заметную долю стенки (Min и др. 2013, Billone и др. 2013). Это та же причина,
что потолок ~0.74 на снимке. Кандидат на исправление — межзёренный канал зарождения со сквозьзёренным
продолжением: по Son и др. 2026, сквозьзёренные гидриды как раз соединяют межзёренные отрезки в длинные цепочки.

## Литература к механизму переориентации: что взято в модель

## Проверка упругого решения

- **Круглое включение с изотропным несоответствием:** внутри напряжение
  однородное, снаружи убывает как 1/r² (0.234 против 0.25 у Эшелби; разница —
  сетка и периодичность).
- **Одна пластинка:** растяжение по нормали у вершины до +250 МПа на 2 мкм,
  сжатие над серединой. Это та же картина, что в моделях автокаталитического
  зарождения.

## Что получилось

### 1. Механизм: направление цепочки переключается при наклоне 45° (рис. 1, 3)

Поле пластинки делает выгодной следующую пластинку у своей вершины. Цепочка из
пластинок с наклоном ±ψ поэтому идёт зигзагом, и направление зигзага резко
переключается при ψ = 45°:

- **|ψ| < 45°** — цепочка вдоль дуги. Это волнистые окружные пакеты из
  наклонных пластинок, которые у Lepine и Cinbiz имеют медиану наклона 19°;
- **|ψ| > 45°** — цепочка по радиусу, то есть «колода карт»;
- **при 45°** взаимодействие пластинок противоположного наклона почти
  исчезает: оба направления равноценны.

Это один и тот же механизм симпатического зарождения для окружных и радиальных
пакетов. В диссертации Lepine (разд. 3.3) механизм группировки радиальных
пакетов назван «неясным и весьма отличным» от окружных.

Что упругое взаимодействие формирует стопки гидридов, а напряжение меняет их
направление, уже показано в фазовом поле: Han et al., Acta Mater. 2019.
Смещённые цепочки от самоускоренного зарождения описаны у Puls. Новым здесь
может быть простой геометрический критерий — 45° — и его проверка на снимках.

**Проверка на снимках Cinbiz** (из диссертации Lepine; пластинки на масштабе
0.6 мкм, пакеты на 4 мкм):

| | в окружных пакетах | в радиальных пакетах |
|---|---|---|
| 0 циклов | 13° (круче 45°: 4 %) | — |
| 1 цикл, 225 МПа | 14° (7 %) | 57° (66 %) |
| 4 цикла, 225 МПа | 14° (12 %) | 52° (58 %) |

Контроль на синтетике: направление пакета сдвигает измеренный наклон
пластинок на 4–6° в свою сторону. С поправкой выходит ≈19° и ≈47–52°: пластинки
окружных пакетов положе 45°, радиальных — круче. Распределение в радиальных
пакетах широкое, 35–40 % длины лежит положе 45°. Подтверждение есть, но не
чистое.

### 2. Калибровка и проверка (рис. 2, 4)

Три параметра:
- **β** — избирательность, 1/МПа;
- **σ_cap** — до какого напряжения учитывается поле соседей (имитирует
  пластическую релаксацию);
- **ℓ** — длина сбора водорода пластинкой.

β и σ_cap подобраны по RHF из табл. 3.1 Lepine при 0 / 200 / 250 МПа:
β = 0.12 1/МПа, σ_cap = 90 МПа. Хорошие пары лежат на линии β·σ_cap ≈ 11: это
сила самоускоренного зарождения. ℓ = 35 мкм выбрана из 20 / 35 / 50 мкм, чтобы
сохранить RHF; на RHF она влияет слабо.

Без ℓ весь водород уходит в 2–3 пакета на поле. Это был артефакт: на стенке
0.8 мм гидрид собирался в двух полосах, а при изгибе — в одной зоне.

| σ, МПа | 0 | 100 | 150 | 200 | 250 |
|---|---|---|---|---|---|
| RHF «по снимку», автомат | 0.10 | 0.40 | 0.58 | 0.70 | 0.70 |
| RHF пакетов, автомат | 0.01 | 0.35 | 0.64 | 0.76 | 0.83 |
| RHF, Lepine (MATLAB / HAPPy) | 0.073 / 0.074 | | | 0.595 / 0.552 | 0.819 / 0.714 |

**Проверки (не подгонялись):**

- **Шаг между радиальными пакетами** при 250 МПа на поле 480 × 480 мкм:
  71–75 мкм при сглаживании 2–6 мкм; у Lepine 70.6–71.1 мкм.
- **Шаг между окружными пакетами** при 0 МПа: 83–88 мкм; у Lepine 57 мкм по 2D
  и ≈100 мкм по 3D.
- **Наклон пластинок** в окружных пакетах 24° (по снимкам ≈19°), в радиальных
  58–67° (по снимкам ≈47–52°). Окружные близко, радиальные на 10–15° круче
  реальных.

### 3. Где минимальная модель не сходится с опытом

Одновременно получить три вещи не удаётся:

1. пологие пластинки в окружных пакетах (19°);
2. RHF 0.77 при 250 МПа;
3. радиальные пакеты из пластинок около 45–50° с резким порогом около 155 МПа
   (рис. 1.3 Lepine: рост RHF укладывается примерно в 10 МПа).

Что пробовали:
- Пологая текстура (χ₀ = 22°) даёт верные 19°, но RHF насыщается на 0.55–0.64.
- Широкий разброс текстуры (35°, согласовано с Кернсом) поднимает RHF, но порог
  уходит к 100 МПа, а радиальные пластинки становятся ещё круче (63–77°).

В модели радиальные пакеты получаются в основном из крутых зёрен, которые
выбирает напряжение, а не за счёт укладки пластинок около 45°. Поэтому RHF
растёт плавно.

**Вывод:** нужен нелинейный коллективный эффект, при котором растущий
радиальный пакет сам усиливает условия для следующих пластинок. Кандидаты:
концентрация приложенного напряжения у концов пакета (пакет как надрез —
пластическая зона или более мягкая граница) или пластическая релаксация,
зависящая от направления. Признак такого эффекта в автомате уже есть: у порога
RHF пакетов сильно скачет от реализации к реализации (см. п. 6).

### 4. Прогноз: порог переориентации зависит от текстуры (рис. 5)

Чем ближе наклон базисных полюсов χ₀ к 45°, тем ниже напряжение переориентации
и тем больше радиальных гидридов даже без нагрузки. Наклон χ₀ взят из
параметров Кернса: χ₀ из ⟨sin²⟩ = f_T / (f_R + f_T) при разбросе 26°.

| текстура | χ₀ | σ при RHF = 0.35 | RHF без нагрузки |
|---|---|---|---|
| ≈ труба Zr-1Nb | 22–24° | 132 МПа | 0.03 |
| лист Zry-4 (калибровка) | 30° | 67 МПа | 0.10 |
| Э635, внутренний слой | 33° | 64 МПа | 0.10 |
| Э635, средний и наружный | 38.5° | 40 МПа | 0.19 |
| Э635, другой образец | 41.5° | 27 МПа | 0.24 |

Абсолютные пороги занижены: для Zry-4 модель даёт 67 МПа вместо ≈155. Надёжнее
порядок и относительный эффект: **канал Э635 (больше базисных полюсов по
окружности, f_T ≈ 0.38) должен переориентироваться легче листа Zry-4 и
заметно легче трубы Zr-1Nb, а внутренний слой — труднее среднего и
наружного.** Пересчёт Кернса в χ₀ двумерный и неточный: при другом разбросе χ₀
сдвигается на 2–5°.

### 5. Стенка с изгибом и выступ ячейки решётки (рис. 6)

**Стенка канала Э635, 0.8 мм**, текстура по слоям (χ₀ = 38.3 / 38.7 / 32.7°
снаружи, в середине и внутри). Напряжение при охлаждении меняется по толщине
линейно, как при изгибе кольца.

| слой (сверху — наружный) | без нагрузки | +200 МПа | изгиб ±100 | изгиб ±200 |
|---|---|---|---|---|
| 0–100 мкм | 0.20 | 0.73 | 0.56 | 0.70 |
| 200–300 мкм | 0.21 | 0.75 | 0.36 | 0.56 |
| 400–500 мкм (нейтраль) | 0.22 | 0.80 | 0.18 | 0.21 |
| 600–700 мкм | 0.24 | 0.70 | 0.11 | 0.02 |
| 700–800 мкм | 0.15 | 0.70 | 0.04 | 0.01 |

При изгибе радиальные гидриды занимают только растянутую часть стенки, а у
сжатой поверхности пакеты окружные, с RHF ниже, чем без нагрузки. Гидрид
распределён по толщине равномерно: 8–21 % на каждый из 8 слоёв.

**Выступ ячейки решётки Zr-1Nb** (стенка 250 мкм, ≈120 wppm, +135 МПа снаружи
и −150 МПа внутри после релаксации — по рукописи МИФИ). RHF по третям толщины:
- после нагрузки: 0.48 / 0.12 / 0.02;
- без нагрузки: 0.11 / 0.07 / 0.08.

Направление совпадает с рукописью: радиальных гидридов больше у наружной
поверхности после отжига под нагрузкой. Числа рукописи (Fn) усреднены по
ячейкам, поэтому количественно не сравниваются.

### 6. Разброс у порога

RHF по 8 реализациям при 100 / 150 / 200 МПа:

| | 100 МПа | 150 МПа | 200 МПа |
|---|---|---|---|
| RHF пакетов | 0.21–0.49 | 0.28–0.79 | 0.61–0.87 |
| RHF «по снимку» | 0.35–0.44 | 0.54–0.60 | 0.63–0.72 |

Отдельные пластинки ведут себя одинаково, а пакеты у порога переключаются
коллективно: на одном и том же поле они уходят то в окружные, то в радиальные.
Значит, на снимке около порога одно поле может сильно отличаться от соседнего,
и для сравнения состояний нужны панорамы.

## Ограничения

- **Двумерная модель:** сечение ND–TD, плоская деформация, след пластинки вместо
  трёхмерной ориентации габитуса.
- **Упругость изотропная и однородная** (гидрид и матрица с одним модулем);
  пластичность учтена только пределом σ_cap.
- **Последовательное зарождение без времени:** нет охлаждения и
  растворимости. Диффузия водорода заменена длиной сбора ℓ и поправкой Горского.
- **Ячейка периодична:** поверхности стенки не свободны ни по упругости, ни по
  водороду.
- **Калибровка по одному набору опытов** (Zry-4, 178 wppm, один цикл). Порог
  не резкий (см. п. 3).
- **Снимки Cinbiz взяты из PDF диссертации**, то есть сжаты. Гистограммы по ним
  в репозиторий не кладутся.

## Что дальше

1. **Проверить механизм 45° на ваших снимках с разрешёнными пластинками:**
   наклон пластинок отдельно в окружных и радиальных пакетах. Предсказание —
   окружные положе 45°, радиальные круче.
2. **Добавить в автомат нелинейную обратную связь:** концентрацию приложенного
   напряжения у концов пакета, а затем итерационную упругость с разными модулями
   гидрида и матрицы (схема Мулинека–Сюке на том же Фурье). Цель — резкий порог
   и «колода» из пластинок около 45°.
   Перебор β и потолка порога не дал (раздел «Перекалибровка β»): для порога нужна
   добавка, не зависящая от σ. Первый кандидат — анизотропия пластичности (МКЭ с
   пластичностью Хилла), она же нужна для двухосности.
3. **Проверить прогноз по текстуре:** переориентация Э635 и Zry-4 (или Zr-1Nb)
   при одинаковых водороде и напряжении. Профиль RHF по толщине канала Э635
   после охлаждения под нагрузкой.
