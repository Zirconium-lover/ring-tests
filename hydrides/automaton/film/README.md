# Ролик «Клеточный автомат зарождения гидридов»

Manim Community 0.19+ с LaTeX (T2A, babel russian); оформление — как у `hydrides_film_v7`:
чёрный фон, Computer Modern, радиальные гидриды красные, окружные — голубые.

| сцена | что показывает |
|---|---|
| `S01_Intro` | постановка: окружные и радиальные гидриды, вопрос — почему пакеты такие |
| `S02_Misfit` | пластинка расширяется, поле напряжений вокруг неё, расчёт через Фурье |
| `S03_Favour` | выгода зарождения новой пластинки 0°, 45°, 90° рядом с уже выросшей |
| `S04_Algorithm` | шаг автомата: поле → выгода → случайный выбор → рост; 60 × 60 мкм, пластинка за пластинкой |
| `S05_Texture` | зёрна и текстура: как напряжение выбирает крутые зёрна |
| `S06_Rule45` | правило 45°: цепочка ±ψ идёт вдоль дуги при ψ < 45° и радиально при ψ > 45° |
| `S07_Check` | наклон пластинок внутри пакетов на снимках Cinbiz |
| `S08_Growth` | рост на поле 200 × 200 мкм при 0, 100, 250 МПа с картой выгоды |
| `S08b_Series` | серия 0–250 МПа и RHF |
| `S08c_Zoom` | крупный план: из чего сложены радиальный и окружный пакеты |
| `S09_Wall` | стенка канала Э635 при изгибе: RHF по глубине |
| `S10_Threshold` | калибровка по Lepine и порог переориентации в зависимости от текстуры |
| `S11_Summary` | выводы |

## Как собрать

```bash
(cd .. && python make_cases.py cases.json && python run_cases.py runs cases.json 4)   # стенка и серия по σ
python film_data.py data ../runs         # прогоны автомата для сцен (несколько минут)
cp ../switch_curve.csv data/
./render.sh -qh                          # все сцены, 1080p30, в media/
```

Сцена `S07_Check` берёт ещё `data/cinbiz_conditional.npy` — углы пластинок, измеренные по снимкам
Cinbiz из диссертации Lepine; в репозитории их нет (производные от чужих снимков).
Папки данных и рендера задаются переменными `FILM_DATA` и `FILM_MEDIA`.
